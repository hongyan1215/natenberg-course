# Natenberg 選擇權自學課程

以 Natenberg《Option Volatility and Pricing》第 2 版的 25 章與附錄 B 為範圍，全部用繁體中文重新編寫的互動課程。講解、例題與練習都是自編的，**不需要讀原書也能學完**。

## 每章怎麼學

1. **讀講義**的「核心概念」；遇到公式，先用自己的話講一次它在說什麼。
2. **做練習**：A 概念題、B 計算題、C 交易情境題、D 挑戰題。先寫下答案，再點開「解答」。
3. **章末測驗**：每章最後有互動題庫，點選即看解析。
4. **自我檢核清單**：能不看筆記做到的項目就打勾（會記住）。
5. 隔天到[綜合測驗](quiz.md)用「只考待複習」把錯題補起來。
