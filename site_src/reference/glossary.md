# 選擇權白話術語表

不用一次背完。讀到不熟的字時，找它回答什麼問題，再回到算例。這裡的金額例子都先以每單位表示；真實金額需再乘合約乘數與口數。

## 合約裡到底寫了什麼？

| 術語 | 用白話理解 | 用一個數字記住 |
|---|---|---|
| **選擇權（option）** | 買方付錢取得有期限的選擇權利；賣方若被指派，必須履行對應義務。 | 付 5 買一張 K100 的買權，5 是權利成本，不是標的買價。 |
| **標的資產（underlying）** | 合約價值連到的資產或指標，例如股票、期貨或指數。 | 標的現價 100，不代表選擇權權利金也是 100。 |
| **買權（call）** | 給持有人用履約價買進標的的權利。 | 市價 120、K100，到期買權價值為 20。 |
| **賣權（put）** | 給持有人用履約價賣出標的的權利。 | 市價 80、K100，到期賣權價值為 20。 |
| **履約價（strike price，K）** | 使用權利時約定的標的交換價格。 | K100 的 call 讓你按 100 買進，不是付 100 買這張合約。 |
| **權利金（premium）** | 選擇權本身的成交價格。買方支付、賣方收到。 | 報價 5、乘數 100，一口權利金為 500。 |
| **到期日（expiration）** | 合約權利結束的日期。期限不同，即使 K 相同也不是同一張合約。 | 剩 30 天與剩 3 天的 K100 買權不能當作同一份部位。 |
| **合約乘數（multiplier）** | 把報價或點數換成金額的倍率，各商品可能不同。 | 每點 50，變動 10 點就是 500。 |
| **履約與指派（exercise / assignment）** | 履約是買方行使權利；指派是賣方接到必須履行義務的通知。 | K100 put 被履約時，被指派的賣方必須按 100 買進。 |
| **美式與歐式（American / European）** | 描述允許履約的時間。美式可依規格提前履約；歐式只在到期履約。 | 美式的「可以提前」不是「應該提前」。 |

想把這幾個字放回同一個故事，讀 [第一課](../start/first-option.md)；要確認結算與交割細節，讀 [第 3 章](../lessons/ch03_contract_specs.md)。

## 你持有什麼，最後怎麼算錢？

| 術語 | 用白話理解 | 用一個數字記住 |
|---|---|---|
| **多頭與空頭部位（long / short）** | long 表示買入並持有合約，short 表示賣出合約建立義務；不能直接翻成看漲或看跌。 | long put 是持有賣權，方向曝險通常受益於下跌。 |
| **開倉與平倉（open / close）** | 開倉是建立部位；平倉是用對應反向交易結束原部位。 | 原有 +1 口買權，再賣 1 口平倉後為 0，不是 −1。 |
| **到期給付（payoff）** | 只看合約到期的經濟價值，先不計買入成本；short 的給付方向相反。 | K100 call、到期 103，買方給付為 3。 |
| **淨損益（profit / loss，P&L）** | 把權利金與其他成本也納入，才知道整筆交易賺多少。 | 上例若付了 5，淨損益是 3 − 5 = −2。 |
| **內含價值（intrinsic value）** | 按目前標的與 K 比較，立即履約的非負經濟價值。 | S103、K100，call 內含價值 3、put 為 0。 |
| **時間價值／外含價值（time / extrinsic value）** | 本課程用「權利金減內含價值」理解剩餘價值。對不同商品與融資條件仍須看規格。 | 買權價格 5、內含 3，差額為 2。 |
| **價內、價平、價外（ITM / ATM / OTM）** | 比較 S 與 K 的位置；價內有正內含價值，價平在 K 附近，價外沒有內含價值。 | S103、K100 call 為價內；這不代表買方已獲利。 |
| **損益兩平（breakeven）** | 在指定條件下淨損益為 0 的位置；要說明是到期或提前平倉。 | 付 5 買 K100 call，到期損益兩平為 105。 |
| **遠期與期貨（forward / futures）** | 雙方先約定未來的交換，兩邊都有義務；期貨有標準化規格與逐日結算等制度。 | 一口乘數 50 的期貨漲 2 點，多單損益為 +100。 |

損益常混淆時，回到 [第 4 章](../lessons/ch04_expiration_pnl.md)逐腿列出給付與權利金，不用先背策略名稱。

## 價格會因為什麼而改變？

| 術語 | 用白話理解 | 用一個數字記住 |
|---|---|---|
| **波動率（volatility）** | 報酬率變動幅度的統計尺度，通常用年化表示；不等於方向。 | 年化 20% 在特定獨立同分布假設下，日標準差約 1.26%。 |
| **隱含波動率（implied volatility，IV）** | 把市場權利金代回選定模型，反推出來的波動率參數。 | IV 從 20% 到 21% 是增加 **1 個百分點**，不是加 1 倍。 |
| **實現波動率（realized volatility，RV）** | 根據指定期間內實際發生的報酬計算的波動率，結果與取樣方法有關。 | 「未來 30 天 RV」要等那 30 天走完才知道。 |
| **Delta（Δ）** | 其他條件固定時，標的小幅變動 1 單位，選擇權價格約變多少。 | Δ0.6、標的 +1，價格一階估計 +0.6；不是保證 60% 會賺。 |
| **Gamma（Γ）** | 標的變動時，Delta 跟著改變的速度。 | Γ0.03、標的 +1，Delta 局部估計增加 0.03。 |
| **Theta（Θ）** | 時間流逝對價格的局部影響，必須確認模型用每日或每年表示。 | 每日 Θ=−0.04，其他條件不變，過一天價格約少 0.04。 |
| **Vega** | 隱含波動率改變時，價格的局部反應；先確認是每 1 個百分點還是每 1.0 波動率。 | 若每 1 個百分點 Vega=0.12，IV20% 到 21% 價格約加 0.12。 |
| **Delta 中性與動態避險（delta neutral / dynamic hedging）** | 先讓整體 Delta 接近零，再隨條件改變調整標的；其他風險仍在。 | 選擇權總 Delta +600 股，空 600 股讓當下一階曝險抵銷。 |
| **買賣權平價與套利（put–call parity / arbitrage）** | 同條件合約可組出相同到期給付，今天價格應符合對應關係；可成交成本會限制套利。 | 無股利、利率 0 的歐式合約：C − P = S − K。 |
| **波動率偏斜（volatility skew）** | 相同到期日，不同履約價的 IV 不同；連同期限形成波動率曲面。 | K90 IV30%、K100 IV20%，差 10 個百分點。 |

Greeks 的數字都是局部估計，會隨市場條件改變。先到 [選擇權價格與 Greeks 工具](../tools/option-explorer.md)，固定其他設定，一次只改一個輸入，再讀 [第 7 章](../lessons/ch07_risk_measurement_1.md)。
