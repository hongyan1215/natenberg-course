# 第 4 章　到期損益（Expiration Profit and Loss）

## ⚡ 懶人包（5 分鐘）

> 時間不多？讀完這一段 + 做下方 ⭐ 必做題就能往下一章走。後面的完整講義當「查字典」用，卡住再回來翻。

**一句話**：到期那天，選擇權只值內含價值。只要記住每條腿的「斜率」（0、+1、−1），把它們加起來，就能畫出任何部位到期時的賺賠圖，像拼樂高一樣。

**你只需要先記住這 5 件事**

1. **到期時只看內含價值。** 價外歸零；價內 call 值「標的 − 履約價」，價內 put 值「履約價 − 標的」。
2. **斜率表要背熟。** 價外 = 0；價內：買 call +1、賣 call −1、買 put −1、賣 put +1；標的多頭永遠 +1、空頭永遠 −1。
3. **多腿部位：斜率直接相加，而且只在履約價轉折。** 光看最左、最右兩段的斜率，就知道大跌、大漲時風險有沒有上限。
4. **兩平點：買 call 是履約價 + 權利金，買 put 是履約價 − 權利金。** 例：買 50 call @3.55 → 兩平 53.55。
5. **複雜部位用「一點 + 斜率」法。** 先在某個履約價算出總損益，再用各區間斜率往左右推，找出所有兩平點。

**必背卡**

| 情況 | 記法 |
|---|---|
| 價外選擇權（買或賣） | 斜率 0 |
| 買價內 call ／賣價內 put | 斜率 +1 |
| 賣價內 call ／買價內 put | 斜率 −1 |
| 標的多頭／空頭 | 永遠 +1 ／ −1 |
| 買 call、賣 call 兩平點 | 履約價 + 權利金 |
| 買 put、賣 put 兩平點 | 履約價 − 權利金 |

**必做練習（約 20 分鐘）**：A2、B1、B3、B5（題號旁標 ⭐，每題都有提示）。其他題目都是選做。

**想看圖？** 打開網站的[策略損益建構器](https://hongyan1215.github.io/natenberg-course/tools/strategy-builder/)工具，自己組跨式、蝶式，看到期損益折線怎麼轉折。

## 本章定位

選擇權在存續期間的價值受很多因素影響，但**到期那一刻**大家一定同意它的價值：就是內含價值。本章教你用「斜率」快速畫出任何複雜部位的到期價值圖（parity graph）與到期損益圖，並計算損益兩平點——這是分析價差策略（[ch10](ch10_intro_spreading.md)～[ch13](ch13_risk_considerations.md)）與合成部位（[ch14](ch14_synthetics.md)）的基本功。前置章節：[ch03](ch03_contract_specs.md)（內含價值）。

> 對應原書：第 4 章〈Expiration Profit and Loss〉，含〈Parity Graphs〉〈Slope〉〈Expiration Profit and Loss〉。

## 學習目標

1. **能列出**任一選擇權在不同到期價格下的價值，並畫出四種基本「曲棍球桿」圖。
2. **能說出**各基本部位在價內／價外時的斜率（0、+1、−1），以及標的部位的斜率。
3. **能用斜率表**畫出多腿、多履約價部位的 parity graph，並判斷上下檔風險是否有限。
4. **能計算**到期損益：先算出一個點的損益，再用斜率推到其他價格。
5. **能求出**所有損益兩平點（breakeven），包括多個兩平點的複雜部位。
6. **能辨認**同一個到期損益可以用不同組合建構（例如兩口 call + 空一口標的 ＝ 跨式）。

## 核心概念

### 4.0 到期時，選擇權只值內含價值

> 💡 **一句話**：到期時答案很簡單：價外值 0，價內值標的價和履約價的差。

新手常被選擇權的數量嚇到：多個到期月 × 多個履約價 × call/put。第一個問題是「選擇權值多少？」——平時很難回答，但**到期時答案很明確**：價外為 0，價內則為標的價與履約價之差。

**例題 4-1（自創）**：55 call 與 45 put 的到期價值。

| 到期標的價 | 55 call | 45 put |
|---|---|---|
| 35 | 0 | 10 |
| 40 | 0 | 5 |
| 45 | 0 | 0 |
| 50 | 0 | 0 |
| 55 | 0 | 0 |
| 60 | 5 | 0 |
| 65 | 10 | 0 |

- 55 call：標的 ≤ 55 時價外、價值 0；高於 55 後，標的每漲 1 點，call 漲 1 點。
- 45 put：標的 ≥ 45 時價外、價值 0；低於 45 後，標的每跌 1 點，put 漲 1 點。

### 4.1 到期價值圖（Parity Graphs）

> 💡 **一句話**：四種曲棍球桿圖：買方風險有限、獲利無限；賣方剛好相反，但看機率仍可能值得賣。

對**買方**而言，內含價值是正值（他能低買高賣）；對**賣方**而言是負值（他被迫高買低賣）。把部位在到期時的價值畫成標的價格的函數，就得到 **parity graph**（parity 即內含價值的別稱）。四種基本形狀因外型被稱為**曲棍球桿圖（hockey-stick diagrams）**：

```
 (1) 買進 call                     (2) 賣出 call
 價值                              價值
  │            /                    │
  │           /  斜率 +1            0 ┼──────────┐
  │          /                      │          \  斜率 −1
 0┼─────────┘                       │           \
  └─────────X────→ 標的             └──────────X─\──→ 標的

 (3) 買進 put                      (4) 賣出 put
 價值                              價值
  │\                                │
  │ \ 斜率 −1                      0 ┼    ┌──────────
  │  \                              │   /
 0┼───└──────────                   │  /  斜率 +1
  └────X─────────→ 標的             └─/X─────────→ 標的
```

**最重要的觀察**：
- **買方**：風險有限（最多賠掉權利金），獲利潛力無限。
- **賣方**：獲利有限（最多賺到權利金），風險無限。

（嚴格說，標的價格不會低於 0，所以 put 的獲利／風險其實有上限；但實務上交易員習慣把 call 和 put 都當成「潛在價值無上限」來思考。）

**那為什麼還有人賣選擇權？** 因為只看「最好和最壞」不夠，還要看**機率**。賣方承擔無限風險，但如果收到的權利金夠多、而發生大虧的機率夠低，這筆交易仍可能划算——這正是 [ch05](ch05_pricing_models.md) 機率與理論價值的主題。

### 4.2 斜率（Slope）

> 💡 **一句話**：價外斜率 0、價內 ±1、標的永遠 ±1；各腿斜率相加，就能畫出任何部位。

選擇權價外時，價值不隨標的變動；價內時則會。**斜率**＝部位價值變動 ÷ 標的價格變動。

| 部位 | 斜率 |
|---|---|
| 買進或賣出任何**價外**選擇權 | 0 |
| 買進價內 call | +1 |
| 賣出價內 call | −1 |
| 買進價內 put | −1 |
| 賣出價內 put | +1 |
| 標的多頭 | **永遠** +1 |
| 標的空頭 | **永遠** −1 |

多腿部位的斜率＝各腿斜率相加。因為選擇權有「保險」特性，**parity graph 一定在履約價處轉折**；標的部位的斜率則與價格無關，也與建倉價格無關。

**例題 4-2：同履約價買 call + 買 put（跨式，straddle）**

| 區間 | call | put | 合計 |
|---|---|---|---|
| 履約價以下 | 0（價外） | −1（價內） | **−1** |
| 履約價以上 | +1（價內） | 0（價外） | **+1** |

```
 價值
  │\             /
  │ \ −1     +1 /
  │  \         /
 0┼───\───────/───
  │    \     /
  └─────\___/──────→ 標的   （到期價值在履約價為 0，往兩邊增加）
         X
```

標的不論往哪個方向遠離履約價都會增值——這類部位在乎的是**波動幅度**而非方向。

**例題 4-3：買 2 口 call + 空 1 口標的（同履約價）**

| 區間 | 2 口 call | 空標的 | 合計 |
|---|---|---|---|
| 履約價以下 | 0 | −1 | **−1** |
| 履約價以上 | +2 | −1 | **+1** |

斜率與例 4-2 完全相同！代表**同一個策略可以用不只一種方式建構**——[ch14](ch14_synthetics.md) 的合成部位就建立在這個觀察上。（標的建倉價格不影響斜率，只影響圖的上下位置。）

**例題 4-4：買 call + 賣 put（同履約價）**

| 區間 | 買 call | 賣 put | 合計 |
|---|---|---|---|
| 履約價以下 | 0 | +1 | **+1** |
| 履約價以上 | +1 | 0 | **+1** |

整條線斜率都是 +1，跟持有標的多頭一模一樣——這就是**合成多頭（synthetic long）**。

**畫任何複雜部位的步驟**：分別找出「最低履約價以下」「每兩個相鄰履約價之間」「最高履約價以上」的總斜率，再把線段接起來。

**例題 4-5：多履約價複雜部位的斜率表（自創）**

部位：
- +2 標的
- −3 口 40 call、+1 口 40 put
- +4 口 45 call、−2 口 45 put
- −1 口 50 call、+3 口 50 put
- −2 口 55 call、−1 口 55 put

| 合約 | 40 以下 | 40–45 | 45–50 | 50–55 | 55 以上 |
|---|---|---|---|---|---|
| −3 40 call | 0 | −3 | −3 | −3 | −3 |
| +1 40 put | −1 | 0 | 0 | 0 | 0 |
| +4 45 call | 0 | 0 | +4 | +4 | +4 |
| −2 45 put | +2 | +2 | 0 | 0 | 0 |
| −1 50 call | 0 | 0 | 0 | −1 | −1 |
| +3 50 put | −3 | −3 | −3 | 0 | 0 |
| −2 55 call | 0 | 0 | 0 | 0 | −2 |
| −1 55 put | +1 | +1 | +1 | +1 | 0 |
| +2 標的 | +2 | +2 | +2 | +2 | +2 |
| **合計** | **+1** | **−1** | **+1** | **+3** | **0** |

```
 斜率：  +1      −1      +1       +3        0
       ───/ \    /    ______/ ‾‾‾‾‾‾‾‾‾‾‾‾‾‾
         /   \  /     /                   （示意，非比例）
 ──────40────45────50────55──────→ 標的
```

解讀（不需要知道 y 軸位置也能讀出風險特性）：
- 40 以下斜率 +1：標的越跌部位越虧，**下檔虧損**一路延伸（直到價格為 0）。
- 55 以上斜率 0：上檔價值固定，**上檔損益有限**。

對多履約價的複雜部位，往往難以直接標出 y 軸位置；但光看斜率就能掌握風險輪廓。

### 4.3 到期損益（Expiration Profit and Loss）

> 💡 **一句話**：損益圖 = 價值圖上下平移權利金；複雜部位先算一點損益，再用斜率推出兩平點。

parity graph 告訴我們部位的「形狀」，但賺賠還取決於**建倉價格**：買選擇權是借方（付錢），賣選擇權是貸方（收錢）。對簡單部位：

$$\text{到期損益圖}=\text{parity graph 向下平移（淨付出）或向上平移（淨收入）}$$

**本章使用的選擇權報價（自創）**：標的現價 **51.00**。

| 履約價 | 40 | 45 | 50 | 55 | 60 |
|---|---|---|---|---|---|
| Call | 11.15 | 6.80 | 3.55 | 1.55 | 0.60 |
| Put | 0.15 | 0.80 | 2.55 | 5.55 | 9.60 |

（這組價格以無利率、波動率 30%、3 個月的模型產生，並滿足 $C-P=S-K$。）

**例題 4-6：買 50 call @3.55**
- 到期標的 ≤ 50：call 歸零，損失 3.55。
- 標的 > 50：斜率 +1。
- **損益兩平**：call 必須值 3.55 → 標的 $=50+3.55=53.55$。

```
 損益
  │                 / 斜率 +1
 0┼──────────────/──────
  │           53.55
−3.55 ────────┘
  └──────────50─────────→ 標的
```

**例題 4-7：賣 45 put @0.80**
- 標的 ≥ 45：put 歸零，獲利 0.80。
- 標的 < 45：斜率 +1（標的每跌 1 點，部位少 1 點）。
- **損益兩平**：$45-0.80=44.20$。

**不同履約價的比較（買進）**

| 部位 | 成本 | 最大損失 | 兩平點 |
|---|---|---|---|
| 買 45 call | 6.80 | 6.80 | 51.80 |
| 買 50 call | 3.55 | 3.55 | 53.55 |
| 買 55 call | 1.55 | 1.55 | 56.55 |
| 買 45 put | 0.80 | 0.80 | 44.20 |
| 買 50 put | 2.55 | 2.55 | 47.45 |
| 買 55 put | 5.55 | 5.55 | 49.45 |

規律：**履約價越低的 call 越值錢**（能以更低價買進），**履約價越高的 put 越值錢**（能以更高價賣出）。到期時，低履約價 call 的價值曲線永遠在高履約價 call 之上（或重合）。

#### 複雜部位的到期損益：「一點 + 斜率」法

對複雜部位，不一定一眼看出淨借或淨貸。步驟：
1. 算出每個區間的斜率。
2. 在某一點（通常選某個**履約價**，最好算）算出總損益。
3. 用斜率往左右推出其他點的損益與兩平點。

**例題 4-8（自創）**：部位與成交價：

| 部位 | 價格 |
|---|---|
| +2 口 45 call | 6.80 |
| −3 口 55 call | 1.55 |
| +1 口 50 put | 2.55 |
| −1 口標的 | 51.00 |

**步驟 1：斜率**

| 合約 | 45 以下 | 45–50 | 50–55 | 55 以上 |
|---|---|---|---|---|
| +2 45 call | 0 | +2 | +2 | +2 |
| −3 55 call | 0 | 0 | 0 | −3 |
| +1 50 put | −1 | −1 | 0 | 0 |
| −1 標的 | −1 | −1 | −1 | −1 |
| **合計** | **−2** | **0** | **+1** | **−2** |

**步驟 2：在 50 的損益**

| 部位 | 成交價 | 50 時價值 | 每口損益 | 總損益 |
|---|---|---|---|---|
| +2 45 call | 6.80 | 5.00 | −1.80 | −3.60 |
| −3 55 call | 1.55 | 0 | +1.55 | +4.65 |
| +1 50 put | 2.55 | 0 | −2.55 | −2.55 |
| −1 標的 | 51.00 | 50.00 | +1.00 | +1.00 |
| **合計** | | | | **−0.50** |

**步驟 3：用斜率推**
- 45–50 斜率 0 → 45 的損益也是 −0.50。
- 45 以下斜率 −2 → 價格每跌 1 點，損益 **+2**：兩平點 $45-0.50/2=44.75$；在 40 為 $-0.50+2\times5=+9.50$。
- 50–55 斜率 +1 → 兩平點 $50+0.50/1=50.50$；在 55 為 $-0.50+5=+4.50$。
- 55 以上斜率 −2 → 兩平點 $55+4.50/2=57.25$；之後虧損無限擴大。

```
 損益
 +9.50 \                     
        \  −2         +4.50
         \              /\
 0 ───────\────────────/──\────────
       44.75\_________/ 50.50 \57.25
           −0.50   −0.50        \ −2
 ──────────45────────50────55──────→ 標的
```

結論：三個兩平點 **44.75、50.50、57.25**；大跌時獲利、溫和上漲（50.50–57.25）時獲利、大漲時虧損無限。

**例題 4-9：已知一點損益，推另一點（自創）**
沿用例 4-5 的部位與斜率（+1、−1、+1、+3、0）。假設已知到期標的為 **38.00** 時，部位損益為 **−1.20**。求標的 57.50 時的損益與所有兩平點。

| 區間 | 起始損益 | 斜率 | 結束損益 |
|---|---|---|---|
| 38.00–40.00 | −1.20 | +1 | $-1.20+1\times2=+0.80$ |
| 40.00–45.00 | +0.80 | −1 | $+0.80-1\times5=-4.20$ |
| 45.00–50.00 | −4.20 | +1 | $-4.20+1\times5=+0.80$ |
| 50.00–55.00 | +0.80 | +3 | $+0.80+3\times5=+15.80$ |
| 55.00–57.50 | +15.80 | 0 | +15.80 |

**標的 57.50 時損益 +15.80**。兩平點（損益變號處）：
- 38–40 之間：$38+1.20/1=39.20$
- 40–45 之間：$40+0.80/1=40.80$
- 45–50 之間：$45+4.20/1=49.20$

## 交易員視角

1. **報價前先想「到期最壞情況」**：做市累積的部位常是許多履約價的雜燴。用斜率表就能立刻知道「大跌／大漲時是否無限虧損」，這比任何模型都快。Optibook 部位上限讓你不會無限放大，但斜率仍告訴你方向性風險在哪裡。
2. **斜率 ≈ 到期時的 delta**：到期時的斜率就是 [ch07](ch07_risk_measurement_1.md) 會學的 delta 的極限值（價內 ±1、價外 0）。到期前 delta 是平滑版本。
3. **多種組合、同一損益**：例 4-3、4-4 顯示 call、put、標的之間可互相合成。若某條腿在 Optibook 上流動性差，可以用另外兩條腿合成同樣的部位，這是做市避險的核心技巧（見 [ch14](ch14_synthetics.md)）。
4. **兩平點不等於好交易**：兩平點只是到期的盈虧分界；這筆交易值不值得做要看「標的落在各區間的機率」，即 [ch05](ch05_pricing_models.md) 的期望值。
5. **到期日的跳空風險**：斜率在履約價突變，到期前一刻標的若在履約價附近徘徊，部位價值對小變動非常敏感（pin risk，見 ch03 情境題）。

## 常見誤區

1. **誤解**：賣選擇權風險無限，所以只有傻瓜才賣。
   **正解**：要同時考慮報酬與機率；權利金足夠、風險可控時賣出可以是正期望值的交易。
2. **誤解**：買 put 在到期圖上的斜率是 +1，因為是「買」。
   **正解**：價內買 put 的斜率是 −1（標的跌，put 漲）；賣價內 put 才是 +1。
3. **誤解**：標的部位的斜率取決於建倉價格。
   **正解**：標的部位斜率永遠是 ±1；建倉價只影響損益圖的上下位置。
4. **誤解**：複雜部位一定要先算出總淨借貸才能畫損益圖。
   **正解**：只要先算出任一點的損益，再用各區間斜率推即可。
5. **誤解**：一個部位只會有一個兩平點。
   **正解**：每次斜率改變都可能穿越 0，複雜部位常有兩個以上兩平點。

## 重點摘要

| 規則 | 內容 |
|---|---|
| 到期價值 | Call $\max(0,S_T-X)$；Put $\max(0,X-S_T)$ |
| 買方 / 賣方 | 買方風險有限、獲利無限；賣方相反 |
| 價外斜率 | 0 |
| 價內斜率 | 買 call +1、賣 call −1、買 put −1、賣 put +1 |
| 標的斜率 | 多 +1、空 −1（永遠） |
| 轉折點 | 只在履約價處 |
| 簡單部位損益 | parity graph 平移權利金 |
| 兩平點 | 買 call：$X+C$；買 put：$X-P$；賣 put：$X-P$；賣 call：$X+C$ |
| 複雜部位 | 斜率表 → 一點損益 → 推其他點 |
| 兩平點公式 | 區間起點 + （起始損益的絕對值 ÷ 斜率的絕對值），在損益變號的區間內 |

## 練習題

> **怎麼練**：先做 ⭐ 必做題（A2、B1、B3、B5）。卡住就先打開「提示」，還是不會再看解答。其他題目選做，想加深或準備面試時再回來。

以下使用本章報價：標的 51.00；Call 40/45/50/55/60 = 11.15/6.80/3.55/1.55/0.60；Put 40/45/50/55/60 = 0.15/0.80/2.55/5.55/9.60。

### A. 概念題

**A1.** 為什麼 parity graph 只會在履約價處轉折？

<details><summary>解答</summary>

選擇權在價外時斜率為 0，價內時為 ±1，唯一改變狀態的地方是標的價格穿過履約價；標的部位的斜率則恆定。因此總斜率只在履約價處改變。

</details>

**A2.** ⭐ 「買 call + 賣 put（同履約價、同到期）」的到期價值圖像什麼？為什麼？

<details><summary>提示</summary>

分成「履約價以下」和「履約價以上」兩段，查斜率表看每段 call 和 put 各是多少，再相加。

</details>

<details><summary>解答</summary>

像持有一口標的多頭：履約價以下，賣出的 put 價內斜率 +1、call 價外 0；履約價以上，call 價內 +1、put 價外 0。全段斜率 +1，即合成多頭。

</details>

**A3.** 某部位最低履約價以下的總斜率是 −2，最高履約價以上是 +1。它的上下檔風險／獲利特性為何？

<details><summary>解答</summary>

最低履約價以下斜率 −2：標的越跌部位越賺，下檔獲利（理論上直到價格為 0）。最高履約價以上斜率 +1：標的越漲越賺，上檔獲利無限。這是一個兩端都獲利的部位（中間可能虧損），類似加權的跨式。

</details>

**A4.** 為什麼履約價較低的 call 在到期時價值永遠不低於履約價較高的 call？

<details><summary>解答</summary>

低履約價 call 能以更低價買進；對任何到期價 $S_T$，$\max(0,S_T-X_1)\ge\max(0,S_T-X_2)$ 當 $X_1<X_2$。

</details>

**A5.** 為什麼光看兩平點不能判斷一筆選擇權交易好不好？

<details><summary>解答</summary>

兩平點只說明到期在哪裡盈虧為零，但沒有告訴我們標的落在各區間的機率與報酬大小。好壞要看機率加權後的期望值（理論價值）與價格的比較。

</details>

### B. 計算題

**B1.** ⭐ 買 55 call @1.55：兩平點？到期標的 60 時損益？最大損失？

<details><summary>提示</summary>

兩平點 = 履約價 + 權利金；到期 60 時 call 值 60 − 55，再扣掉付出的 1.55。

</details>

<details><summary>解答</summary>

兩平點 $55+1.55=56.55$；在 60：$5-1.55=+3.45$；最大損失 1.55。

</details>

**B2.** 賣 50 put @2.55：兩平點？到期標的 44 時損益？最大獲利？

<details><summary>解答</summary>

兩平點 $50-2.55=47.45$；在 44：$-(50-44)+2.55=-3.45$；最大獲利 2.55（標的 ≥ 50）。

</details>

**B3.** ⭐ 買 50 跨式（買 50 call + 買 50 put）：總成本？兩個兩平點？到期 44 與 58 的損益？

<details><summary>提示</summary>

總成本 = call + put 權利金；兩平點是 50 往下、往上各一個總成本；某價格的損益 = 價內那一腿的內含價值 − 總成本。

</details>

<details><summary>解答</summary>

成本 $3.55+2.55=6.10$；兩平點 $50-6.10=43.90$、$50+6.10=56.10$。
在 44：$6-6.10=-0.10$；在 58：$8-6.10=+1.90$。

</details>

**B4.** 改以「買 2 口 50 call + 在 51.00 賣 1 口標的」建構。計算到期 44 與 58 的損益，並與 B3 比較。

<details><summary>解答</summary>

在 44：call 歸零 $2\times(-3.55)=-7.10$；標的 $-(44-51)=+7.00$；合計 −0.10。
在 58：$2\times(8-3.55)=+8.90$；標的 $-(58-51)=-7.00$；合計 +1.90。
與 B3 完全相同——兩種組合斜率相同、在本報價下位置也相同。

</details>

**B5.** ⭐ 蝶式：+1 口 45 call、−2 口 50 call、+1 口 55 call。求淨成本、各區間斜率、最大獲利與兩平點。

<details><summary>提示</summary>

先算淨成本（買的付錢、賣的收錢）；再列各區間斜率；最大獲利出現在中間履約價 50，用 50 的價值減淨成本。

</details>

<details><summary>解答</summary>

淨成本 $6.80-2\times3.55+1.55=1.25$（借方）。
斜率：45 以下 0；45–50 +1；50–55 −1；55 以上 0。
最大獲利在 50：$5-1.25=3.75$。兩平點 $45+1.25=46.25$、$55-1.25=53.75$。

</details>

**B6.** 例 4-9 的部位，已知 38.00 時損益 −1.20。求標的 42.00 與 52.00 時的損益。

<details><summary>解答</summary>

- 40 時 +0.80；40–45 斜率 −1 → 42 時 $0.80-2=-1.20$。
- 50 時 +0.80；50–55 斜率 +3 → 52 時 $0.80+3\times2=+6.80$。

</details>

### C. 交易情境題

**C1.** 你預期標的 51 在到期前會漲到 57 左右，但不確定。可選擇：買 50 call（3.55）、買 55 call（1.55）、買 1 口 45/55 多頭價差（買 45 call、賣 55 call）。在到期價 57 與 53 兩種情境下比較三者損益，並說明各自的取捨。

<details><summary>解答</summary>

- 50 call：57 → $7-3.55=+3.45$；53 → $3-3.55=-0.55$。
- 55 call：57 → $2-1.55=+0.45$；53 → $-1.55$。
- 45/55 價差（成本 $6.80-1.55=5.25$）：57 → $10-5.25=+4.75$；53 → $8-5.25=+2.75$。
取捨：55 call 最便宜但需要大漲；50 call 中庸；價差在溫和上漲時表現最好，但獲利封頂在 4.75（大漲到 65 時，50 call 會賺 11.45）。若你的看法是「漲到 57 左右」而不是「暴漲」，價差最貼合觀點。

</details>

**C2.** 做市一天後，你的部位斜率表顯示：最低履約價以下 −3、最高履約價以上 −4。今晚有重大消息，你擔心什麼？可以如何用最少的交易修正？

<details><summary>解答</summary>

下檔斜率 −3 代表大跌時獲利；上檔斜率 −4 代表大漲時每點虧 4 口標的的錢，且無上限。最擔心大漲。最直接的修正是買進標的（例如 +4 口）讓上檔斜率變 0，但這會讓下檔斜率變 +1（大跌時虧損）；或買進高履約價 call（價外、便宜）把上檔斜率拉回，同時不影響下檔斜率。實際選擇取決於報價與部位上限。

</details>

### D. 挑戰題

**D1.** 證明「買 45 call、賣 55 call」與「買 45 put、賣 55 put」的到期損益在本章報價下完全相同，並說明這與報價滿足 $C-P=S-K$ 的關係。

<details><summary>解答</summary>

**斜率**：兩者都是 45 以下 0、45–55 +1、55 以上 0。
**位置**：
- call 價差：淨付 $6.80-1.55=5.25$；45 以下損益 −5.25，55 以上 $10-5.25=+4.75$，兩平 50.25。
- put 價差：淨收 $5.55-0.80=4.75$；55 以上兩個 put 皆價外，損益 +4.75；45 以下 $4.75-10=-5.25$。
兩者斜率與一點損益都相同，所以整條線相同。
**原因**：每個履約價都有 $C_K-P_K=S-K$。call 價差成本 $C_{45}-C_{55}=(P_{45}+S-45)-(P_{55}+S-55)=P_{45}-P_{55}+10$，因此 $-(C_{45}-C_{55})=(P_{55}-P_{45})-10$：call 價差的「下檔損益」恰等於 put 價差的「下檔損益」。這就是 [ch14](ch14_synthetics.md) 合成關係與 [ch15](ch15_option_arbitrage.md) 買賣權平價的雛形；若報價違反此關係，就有套利空間。

</details>
