# 第 15 章　選擇權套利（Option Arbitrage）

## ⚡ 懶人包（5 分鐘）

> 時間不多？讀完這一段 + 做下方 ⭐ 必做題就能往下一章走。後面的完整講義當「查字典」用，卡住再回來翻。

**一句話**：同一樣東西不能有兩個價錢。「買權 − 賣權」合成出來的標的，價格必須跟真的標的對得上（買賣權平價）；對不上就有人來套利，而所謂「無風險套利」其實也藏著好幾種風險。

**你只需要先記住這 5 件事**

1. **買賣權平價：買權 − 賣權 = 遠期價 − 履約價（再折現）。** 期貨型結算的期貨選擇權最簡單：C − P = F − X，不用折現。例：250C 12.40、250P 7.15 → 期貨應為 255.25。
2. **combo（C − P）太貴 → conversion（買標的、賣買權、買賣權）；太便宜 → reversal（反過來）。** 記法：在便宜的市場買、在貴的市場賣。
3. **股票快速心算：C − P ≈ 股價 − 履約價 + 履約價的利息 − 股利。** 平價看起來不平，先懷疑自己的利率或股利假設，再想套利。
4. **套利不是零風險。** 五種風險：執行（補不到腿）、pin（到期剛好在履約價，不知道會不會被指派）、結算方式不同、利率、股利。現金結算沒有 pin risk。
5. **盒式 = 履約價差的現值，等於一筆借貸；roll = 兩個日曆價差的「差」。** 盒式是兩個垂直價差的「和」，別記反。

**必背卡**

| 要算什麼 | 怎麼算 |
|---|---|
| 平價（期貨型結算） | C − P = F − X |
| 平價（股票型結算） | C − P = (F − X) ÷ (1 + rt) |
| 股票遠期 | F = S × (1 + rt) − 股利 |
| 股票快速近似 | C − P ≈ S − X + X × r × t − 股利 |
| 盒式價值 | 履約價差 ÷ (1 + rt) |
| 合成期貨 delta（股票型結算選擇權） | 100 ÷ (1 + rt) |

**必做練習（約 20 分鐘）**：A1、B1、B3、C1（題號旁標 ⭐，每題都有提示）。其他題目都是選做。

## 本章定位

第 14 章說明合成部位「長得像」真實合約；本章要回答「它應該值多少」。答案就是**買賣權平價**（put-call parity），以及由它衍生的轉換（conversion）、逆轉換（reversal）、盒式（box）、捲式（roll / jelly roll）與時間盒式（time box）。最後會看到這些套利結構其實不是「無風險」：執行、pin、結算、利率與股利都可能咬你一口。前置：[ch02](ch02_forward_pricing.md)（遠期價格）、[ch03](ch03_contract_specs.md)（股票型 vs 期貨型結算）、[ch14](ch14_synthetics.md)。

## 學習目標

1. 能從現金流推導買賣權平價，並寫出期貨（期貨型結算、股票型結算）與股票（含股利）三種版本。
2. 能判斷價格偏離時應做 conversion 還是 reversal，並計算套利利潤。
3. 能用快速近似式 $C - P \approx S - X + Xrt - D$ 估算 combo，並反推隱含利率、隱含股利。

5. 能計算 box、roll（jelly roll）、time box 的理論價值，並把它們拆解成垂直價差、日曆價差或對角價差。
6. 能利用合成關係，在有買賣價差的市場中找出執行跨式或蝶式的最便宜方式。

## 核心概念

### 15.1 合成空頭 vs 直接賣標的；conversion 與 reversal

> 💡 **一句話**：合成標的和真標的一買一賣就是 conversion／reversal：combo 太貴做 conversion，太便宜做 reversal。

**直覺**：標的 76.00。你想放空，可以直接賣標的，也可以「賣 12 月 75C 收 4.30、買 12 月 75P 付 3.30」：淨收 1.00。到期時一定以 75 賣出標的，加上收到的 1.00，等於以 76.00 放空。只要 75C 比 75P 剛好貴 1.00（且不考慮利息、股利），兩種放空方式損益完全相同。

**組合起來**：若你已有合成空頭（−75C、+75P），可以買進標的來對沖：

| 名稱 | 組成 | 白話 |
|---|---|---|
| **conversion（轉換）** | 買標的 + 賣買權 + 買賣權 | 在標的市場買、在選擇權市場合成賣 |
| **reversal / reverse conversion（逆轉換）** | 賣標的 + 買買權 + 賣賣權 | 在標的市場賣、在選擇權市場合成買 |

（買權、賣權同履約價、同到期。合成部分「買權 − 賣權」常被交易員稱為 **combo**。）

- 合成部分（combo）相對標的**太貴** → 賣 combo、買標的 → **conversion**。
- 合成部分**太便宜** → 買 combo、賣標的 → **reversal**。

### 15.2 從現金流推導買賣權平價

> 💡 **一句話**：把 conversion 的收入和支出列出來令它相等，就得到 C − P = (F − X) 的現值。

做一個 conversion（股票標的、持有到到期、單利 $r$、期間 $t$）：

| 收入 | 支出 |
|---|---|
| 賣買權收 $C$ | 買賣權付 $P$ |
| $C$ 的利息 $Crt$ | 借錢買賣權的利息 $Prt$ |
| 持有股票領股利 $D$ | 買股票付 $S$ |
| 到期以 $X$ 賣出股票（履約賣權或被指派買權） | 借錢買股票的利息 $Srt$ |

無套利 → 收入 = 支出：

$$C(1+rt) + D + X = P(1+rt) + S(1+rt)$$

移項：$(C-P)(1+rt) = S(1+rt) - D - X$。右邊的 $S(1+rt) - D$ 正是股票遠期價格 $F$：

$$\boxed{C - P = \frac{F - X}{1 + rt}}$$

**買賣權平價**：歐式同履約價、同到期的買權與賣權價差，等於「遠期價格減履約價」的現值。交易員也稱之為 combo value、synthetic relationship 或 conversion market。

### 15.3 期貨選擇權

> 💡 **一句話**：期貨型結算 C − P = F − X；股票型結算要再除以 (1 + rt)。

**(a) 期貨型結算**（美國以外多數期貨交易所）：買賣期貨或選擇權都不需付現，有效利率為 0；期貨也沒有股利：

$$C - P = F - X$$

**例題 15-1**　12 月 250C = 12.40、12 月 250P = 7.15。期貨應為 $250 + 12.40 - 7.15 =$ **255.25**。

若期貨實際在 255.60：$12.40 - 7.15 = 5.25 \ne 255.60 - 250 = 5.60$。合成（combo）比期貨便宜 → 人人都想做 **reversal**：買 250C、賣 250P、賣期貨，鎖定 0.35 的利潤。

市場壓力會讓價格回到平價，可能是：
- 買權被買到 12.75（12.75 − 7.15 = 5.60），或
- 賣權被賣到 6.80（12.40 − 6.80 = 5.60），或
- 期貨被賣到 255.25，或三者組合。

交易所每日結算價也會刻意維持平價。**示意結算表**（自創，期貨型結算，期貨 131.20）：

| 履約價 | 買權 | 賣權 | C − P | F − X |
|---|---|---|---|---|
| 129 | 2.68 | 0.48 | 2.20 | 2.20 |
| 130 | 1.92 | 0.72 | 1.20 | 1.20 |
| 131 | 1.29 | 1.09 | 0.20 | 0.20 |
| 132 | 0.80 | 1.60 | −0.80 | −0.80 |
| 133 | 0.46 | 2.26 | −1.80 | −1.80 |

**(b) 股票型結算**（北美多數期貨交易所）：選擇權要付現，必須折現：

$$C - P = \frac{F - X}{1 + rt}$$

**例題 15-2**　4 個月、利率 4.5%、12 月期貨 248.00、12 月 250C = 6.10。

$$C - P = \frac{248 - 250}{1 + 0.045 \times 4/12} = \frac{-2}{1.015} = -1.97$$

$P = 6.10 + 1.97 =$ **8.07**。

### 15.4 漲跌停鎖死的期貨市場（Locked Futures Markets）

> 💡 **一句話**：期貨漲停鎖死時，可以從 C − P + X 看出期貨「真正」該在哪裡。（可先跳過）

期貨碰到漲跌停時無法成交，但選擇權市場可能仍開放——可以透過合成部位「在漲停價之外」交易期貨，價格由 $F = C - P + X$ 推得。

**例題 15-3**（自創）期貨每日漲跌幅限 10，昨收 480，今日漲停 490 鎖死。選擇權（期貨型結算、無利息）報價：

| 履約價 | 買權 | 賣權 | 合成期貨 $C - P + X$ |
|---|---|---|---|
| 480 | 19.10 | 2.80 | 496.30 |
| 485 | 15.40 | 4.15 | 496.25 |
| 490 | 12.10 | 5.75 | 496.35 |
| 495 | 9.20 | 7.90 | 496.30 |
| 500 | 6.85 | 10.60 | 496.25 |
| 505 | 4.95 | 13.65 | 496.30 |

若期貨能自由交易，大概在 496.25–496.35。想買期貨的人可以買 C、賣 P 合成買進；想賣的人反向操作。小幅差異可能來自買賣價差未列出或報價時間不同。

### 15.5 股票選擇權

> 💡 **一句話**：股票先算遠期價（加利息、扣股利），再套平價。

先算遠期，再套平價。

**例題 15-4**　股價 84.20、5 個月、利率 3.6%、到期前股利 0.60、80C = 7.35。求 80P。

$$F = 84.20 \times (1 + 0.036 \times 5/12) - 0.60 = 85.463 - 0.60 = 84.863$$
$$C - P = \frac{84.863 - 80}{1.015} = 4.791$$
$$P = 7.35 - 4.79 = \textbf{2.56}$$

### 15.6 股票選擇權的快速近似

> 💡 **一句話**：C − P ≈ S − X + Xrt − D 可秒算；不平時也可能是利率或股利假設錯了。

在交易廳需要秒算時，可以把平價展開：

$$C - P = \frac{S(1+rt) - D - X}{1+rt} = S - \frac{D}{1+rt} - \frac{X}{1+rt}$$

近似：股利相對小 → $\frac{D}{1+rt} \approx D$；$\frac{X}{1+rt} \approx X - Xrt$。於是

$$\boxed{C - P \approx S - X + Xrt - D}$$

白話：**combo ≈ 股價 − 履約價 + 履約價的利息 − 股利**。

**例題 15-5**　同例題 15-4：$84.20 - 80 + 80 \times 0.036 \times 5/12 - 0.60 = 4.80$，與精確值 4.79 只差約 0.01。利率高、股利大、天期長時誤差變大，但短天期很好用。

**反推隱含利率與隱含股利**：平價有三個價格（C、P、S）與兩個假設（r、D）。價格「看起來不平」時，未必是套利，可能是你的假設錯了。

**例題 15-6**　60C = 5.10、60P = 1.25、3 個月、你假設 r = 5%、D = 0.35。

$$S \approx C - P + X - Xrt + D = 5.10 - 1.25 + 60 - 0.75 + 0.35 = 63.45$$

但股票實際在 63.30。

- 若價格與股利都對，**隱含利率**：$r = \dfrac{(C - P - S + X + D)/X}{t} = \dfrac{(3.85 - 63.30 + 60 + 0.35)/60}{0.25} = \dfrac{0.015}{0.25} =$ **6.0%**
- 若價格與利率都對，**隱含股利**：$D = S - C + P - X + Xrt = 63.30 - 3.85 - 60 + 0.75 =$ **0.20**

市場可能在預期公司減息（0.35 → 0.20），或你的資金成本假設偏低。

### 15.7 套利風險（Arbitrage Risk）

> 💡 **一句話**：套利有執行、pin、結算、利率、股利五種風險；大部位別帶著價平空頭進到期。

conversion/reversal 常被說成「無風險」，但幾乎沒有策略真的零風險。

#### (1) 執行風險（Execution Risk）

沒人會一次把有利可圖的三腿送到你面前，你常要先做一兩腿、再等最後一腿。例如先買賣權與股票，打算稍後賣買權完成 conversion——若買權價格下跌，可能永遠無法以有利價格完成。**任何分腿執行的策略，都承擔補腿前價格不利變動的風險。**

#### (2) Pin 風險（Pin Risk）

假設你持有 300 組 75 conversion（−75C、+75P、+股票）。到期時：

- 標的 > 75：被指派買權，股票交出 → 無部位。
- 標的 < 75：履約賣權，股票賣出 → 無部位。
- **標的剛好 75.00**：你要不要履約賣權？取決於買權會不會被指派——但指派通知隔天才知道，那時賣權已經到期。

價平到期的選擇權**常常會被履約**：想建立標的部位的持有人，履約的成本通常比在市場上買賣標的低。

- 猜「會被指派」而不履約賣權 → 若沒被指派，隔天多出 300 口不想要的多頭股票。
- 猜「不會被指派」而履約賣權 → 若被指派，隔天多出 300 口空頭股票。

conversion/reversal 往往規模很大，猜錯的代價很高。

**對策**：
- 到期前標的接近履約價時，**縮小部位**；不要帶著大量價平空頭選擇權進入到期。
- 臨到期仍有剩餘時，可以直接平倉（但要吃買賣價差），或者找持有反向部位（reversal）的人以**平價（even money）**互相交叉平倉——雙方都消除 pin risk，利潤早在開倉時就鎖定了。
- **現金結算**的選擇權（如多數指數選擇權）到期不產生標的部位，**沒有 pin risk**。

#### (3) 結算風險（Settlement Risk）

當**選擇權與標的的結算方式不同**時出現（股票型結算的選擇權 + 期貨型結算的期貨）。

**例題 15-7**　期貨 151、150 履約價、6 個月、利率 6%、選擇權股票型結算。合理 combo = $1/(1 + 0.06 \times 0.5) = 0.971$。你賣 150C 收 8.75、買 150P 付 7.75（combo 收 1.00）、買期貨 151 → 鎖定約 0.03 的 conversion 利潤。

- 期貨隨後跌到 145：選擇權部位（合成空頭）有 6.00 的**未實現**獲利；期貨部位卻**立刻**被扣 6.00 的變動保證金。為這 6.00 融資半年要約 $6 \times 0.06 \times 0.5 = 0.18$ 的利息——遠超過 0.03 的預期利潤。若資金不足還可能被迫平倉。
- 期貨漲到 157：期貨立刻入帳 6.00 可生息，選擇權虧損未實現 → 額外賺利息。

所以這個 conversion 其實偏多。以 Black 模型（波動率 20%）：

| 部位 | delta |
|---|---|
| 賣 150C | −53 |
| 買 150P | −44 |
| 買期貨 | +100 |
| 合計 | **+3** |

一般公式：股票型結算的期貨選擇權，合成期貨部位的 delta 為

$$\Delta_{\text{synthetic}} = \frac{100}{1 + rt}\quad（\text{本例 } 100/1.03 = 97.1）$$

利率越高、天期越長，偏離 100 越多。做 300 組時，+2.9 × 300 ≈ +870 delta，相當於多出約 9 口期貨的方向部位。若兩者結算方式相同（都股票型或都期貨型），就沒有這個風險。（用期貨避險現貨部位時也有類似問題，稱為 tailing。）

#### (4) 利率與股利風險（Interest and Dividend Risk）

股票 conversion（−C、+P、+股票）整體是**付出**約等於履約價的金額，需要融資：

- 利率上升 → 融資成本上升 → conversion 價值下降 → **conversion 的 rho 為負**。
- reversal 賣股票收現金生息 → **rho 為正**。
- conversion 持有股票 → 股利增加有利（**正股利風險**）；reversal 相反。

（股票選擇權中買權 rho 為正、賣權 rho 為負；conversion 是賣買權、買賣權，兩者 rho 同號相加。）

**例題 15-8**　沿用例題 15-5 的近似：combo = 4.80。
- 利率由 3.6% 升到 4.6%：$84.20 - 80 + 80 \times 0.046 \times 5/12 - 0.60 = 5.13$（combo 上升 0.33，賣出 combo 的 conversion 受損）。
- 股利由 0.60 提高到 0.80：combo = 4.60（下降 0.20，conversion 受益）。

（融資通常是浮動利率，所以利率風險真實存在。）

**三方組合（three-way）**：conversion/reversal 的風險來自「合成部位 vs 真實標的」的差異。可以把真實標的換成**深價內選擇權**（delta ≈ 100）：

- conversion：−C、+P、+深價內買權；或 −C、+P、−深價內賣權。

這消除了股票部位的融資、股利或結算問題，但若標的往深價內那張的履約價移動，它不再像標的，整個部位也不再像 conversion。

### 15.8 盒式價差（Boxes）

> 💡 **一句話**：盒式到期一定值履約價差，今天值它的現值；買盒式 = 放款、賣盒式 = 借款。

把真實標的換成「另一個履約價的合成部位」：

- 6 月 150 conversion：−150C、+150P、+標的
- 6 月 140 reversal：+140C、−140P、−標的

標的抵銷 →

| 左側（140 合成多頭） | 右側（150 合成空頭） |
|---|---|
| +1 140C | −1 150C |
| −1 140P | +1 150P |

這就是**多頭 140/150 盒式**（long box）：低履約價合成多頭、高履約價合成空頭。反過來是空頭盒式。它在 140 履約價市場買、在 150 履約價市場賣，同一標的，所以是套利。

**價值**：到期時一定在 140 買、在 150 賣，價值恆為 10（不計 pin risk）。
- 期貨型結算：今天就值 10。
- 股票型結算：今天值現值。4 個月、利率 6%：$10/(1+0.06 \times 4/12) = 9.804$。

**盒式 = 借貸**：歐式、現金結算時，買盒式 = 放款、賣盒式 = 借款。以 9.75 賣出上述盒式等於借錢，隱含年利率 $(10/9.75 - 1)/(4/12) =$ **7.69%**。賣得越便宜，借款利率越高。交易公司缺短期資金時，有時會賣盒式籌資（但仍有保證金與交易成本）。

**上下拆解**：

| 上半部 | +140C / −150C → 多頭買權價差 |
|---|---|
| 下半部 | −140P / +150P → 空頭賣權價差 |

**多頭盒式 = 多頭買權價差 + 空頭賣權價差**，兩個垂直價差的價格和必等於盒式價值。

**例題 15-9　用盒式報價**　140/150 盒式值 9.80（取整），140/150 買權價差市場 6.35。有人問 140/150 賣權價差的報價：中心價 = 9.80 − 6.35 = **3.45**，報 3.40–3.50。
- 若你以 3.40 買到賣權價差，再以 6.35 買買權價差 → 9.75 買到值 9.80 的盒式。
- 若你以 3.50 賣出賣權價差，再以 6.35 賣出買權價差 → 9.85 賣出值 9.80 的盒式。

盒式比 conversion/reversal 更低風險（沒有標的部位）。

### 15.9 捲式（Rolls / Jelly Rolls）

> 💡 **一句話**：roll ≈ 履約價的利息 − 股利，等於買權日曆價差減賣權日曆價差。（可先跳過）

盒式是同月份、不同履約價的 conversion + reversal；**捲式**是同履約價、不同月份：

| 近月（6 月） | 遠月（9 月） |
|---|---|
| +1 6 月 70C | −1 9 月 70C |
| −1 6 月 70P | +1 9 月 70P |
| （−標的） | （+標的） |

標的抵銷的前提是兩個月份的標的相同——股票選擇權成立；期貨選擇權各月份對應不同期貨，不是真正的 roll。

**多頭捲式**（本書定義：買遠月合成、賣近月合成；業界常稱 **jelly roll**）：

$$\text{價值} = (C_l - P_l) - (C_s - P_s)$$

（$l$ 遠月、$s$ 近月）。無股利時 $C - P = S - X/(1+rt)$，所以

$$\text{roll} = \frac{X}{1 + r_s t_s} - \frac{X}{1 + r_l t_l} - D$$

$D$ 為兩次到期之間的股利（忽略股利的利息）。通常為正：近月的履約價折現較少。

**例題 15-10**　6 月（3 個月）/9 月（6 個月）70 roll，利率 5%，兩到期間股利 0.50：

$$\frac{70}{1.0125} - \frac{70}{1.025} - 0.50 = 69.136 - 68.293 - 0.50 = \textbf{0.343}$$

**快速近似**：持有 roll 的人（賣近月合成、買遠月合成）會在近月到期以 X 賣出股票、遠月到期以 X 買回，期間等於放空股票：賺 X 的利息、付股利：

$$\text{roll} \approx X \cdot r \cdot (t_l - t_s) - D = 70 \times 0.05 \times 0.25 - 0.50 = 0.375$$

誤差約 0.03。

**用日曆價差表示**：

| 上半部 | −6 月 70C / +9 月 70C → 多頭買權日曆價差 |
|---|---|
| 下半部 | +6 月 70P / −9 月 70P → 空頭賣權日曆價差 |

**多頭 roll = 買買權日曆價差 + 賣賣權日曆價差**，所以兩個日曆價差的**差**等於 roll：

- 70 買權日曆價差 2.60 → 70 賣權日曆價差 = 2.60 − 0.343 ≈ **2.26**。
- 70 賣權日曆價差 2.10 → 70 買權日曆價差 ≈ 2.44。

一般利息大於股利，所以 roll 為正、買權日曆價差較貴；股利大於利息時 roll 為負，關係反轉。（注意：盒式 = 兩個垂直價差的**和**；roll = 兩個日曆價差的**差**。）

**不同履約價的 roll**：股利對同到期的 roll 都一樣，差別只在履約價的利息：

$$\text{roll}_{60} \approx \text{roll}_{70} - (70 - 60) \times 0.05 \times 0.25 = 0.343 - 0.125 = 0.218$$

（精確值 0.223。）roll 只消除到近月到期為止的標的風險；近月到期時會實際買賣股票，所以 roll 對利率與股利變化敏感，兩到期日相隔越久越敏感。

### 15.10 時間盒式（Time Boxes / Diagonal Rolls）

> 💡 **一句話**：時間盒式 = 盒式 ± roll，也能拆成兩個對角價差。（可先跳過）

不同月份**且**不同履約價：

| 近月 | 遠月 |
|---|---|
| +1 6 月 70C | −1 9 月 80C |
| −1 6 月 70P | +1 9 月 80P |

（6 月合成買進 70、9 月合成賣出 80。）

$$\text{價值} = (C_{s,70} - P_{s,70}) - (C_{l,80} - P_{l,80}) = \frac{X_l}{1 + r_l t_l} + D - \frac{X_s}{1 + r_s t_s}$$

**例題 15-11**　同例題 15-10 條件：

$$\frac{80}{1.025} + 0.50 - \frac{70}{1.0125} = 78.049 + 0.50 - 69.136 = \textbf{9.413}$$

正值代表建立此部位要**付出** 9.41（6 月以 70 買、9 月以 80 賣，當然要先付錢）。

**拆成兩個對角價差**：買權對角（+6 月 70C、−9 月 80C）與賣權對角（−6 月 70P、+9 月 80P）。賣權那組一定是付出（9 月 80P 一定比 6 月 70P 貴），買權那組可付可收（低履約價使 6 月較貴、長時間使 9 月較貴）。不論如何，兩者合計為 9.41：若買權對角成交 3.10，賣權對角應為 6.31。

**時間盒式 = 盒式 ± roll**：

| 拆法 | 計算 |
|---|---|
| 買 6 月 70/80 盒式 + 賣 6/9 月 80 roll | $\frac{10}{1.0125} - \left(\frac{80}{1.0125} - \frac{80}{1.025} - 0.50\right) = 9.877 - 0.464 = 9.413$ |
| 買 9 月 70/80 盒式 + 賣 6/9 月 70 roll | $\frac{10}{1.025} - 0.343 = 9.756 - 0.343 = 9.413$ |

即：**買近月盒式 + 賣較高履約價的 roll**，或**買遠月盒式 + 賣較低履約價的 roll**，結果相同。

### 15.11 在波動率價差中運用合成

> 💡 **一句話**：真套利很少，但用合成可以把跨式、蝶式買得更便宜一點。

真正的套利機會很少、很小、很短，通常只有交易成本極低的專業交易員吃得到。但懂得套利關係，可以讓你用**更好的價格**執行原本就想做的策略。

**例題 15-12　最便宜的跨式**（3 個月、利率 4%、股利 0.30）

| | Bid | Ask |
|---|---|---|
| 股票 | 63.40 | 63.45 |
| 60C | 5.05 | 5.15 |
| 60P | 1.30 | 1.35 |

近似平價：$C - P \approx S - 60 + 60 \times 0.04 \times 0.25 - 0.30 = S - 59.70$。

- 直接買：5.15 + 1.35 = **6.50**
- 合成賣權（買 60C、賣股票 63.40）：$5.15 - P = 63.40 - 59.70 = 3.70$ → 合成賣權成本 1.45 > 1.35，較差。
- 合成買權（買 60P、買股票 63.45）：$C - 1.35 = 63.45 - 59.70 = 3.75$ → 合成買權成本 **5.10** < 5.15。
- 以合成買權買跨式（買 2 張 60P、買股票）：5.10 + 1.35 = **6.45**，省 0.05。

但沒有套利：
- conversion（賣 60C 5.05、買 60P 1.35、買股票 63.45）：合成賣出價 3.70 < 買進成本 3.75。
- reversal（買 60C 5.15、賣 60P 1.30、賣股票 63.40）：合成買進價 3.85 > 賣出價 3.70。

0.05 值不值得？專業交易員大量交易、手續費低，會很高興；散戶多一腿的手續費與執行難度，可能讓直接買跨式更實際。

**例題 15-13　最便宜的蝶式**（同條件，55/60/65）

| | Bid | Ask |
|---|---|---|
| 55C | 9.20 | 9.35 |
| 55P | 0.55 | 0.60 |
| 60C | 5.05 | 5.15 |
| 60P | 1.30 | 1.35 |
| 65C | 2.20 | 2.30 |
| 65P | 3.40 | 3.55 |

- 買權蝶式：−9.35 + 2×5.05 − 2.30 = 付 **1.55**
- 賣權蝶式：−0.60 + 2×1.30 − 3.55 = 付 **1.55**
- 賣鐵蝶式：賣 60C 5.05、賣 60P 1.30、買 55P 0.60、買 65C 2.30 → 收 **3.45**

蝶式 + 鐵蝶式 = $5/(1 + 0.04 \times 0.25) = 4.950$。以 3.45 賣鐵蝶式 ≡ 以 4.95 − 3.45 = **1.50** 買蝶式，比直接買便宜 0.05。（可自行驗證：此報價下各 conversion、reversal、box 都沒有套利。）

> 每次執行策略前問自己：**有沒有哪一部分可以用合成方式做得更便宜？** 通常沒有，但一輩子累積下來，小小的節省也很可觀。

### 15.12 套利關係總表（歐式、不計股利利息）

> 💡 **一句話**：所有平價、盒式、roll 公式的對照表，忘了再回來查。

| 關係 | 單利 | 連續複利 | 近似 |
|---|---|---|---|
| 平價（期貨，股票型結算） | $C - P = \frac{F - X}{1 + rt}$ | $(F - X)e^{-rt}$ | — |
| 平價（期貨，期貨型結算） | $C - P = F - X$ | 同左 | — |
| 平價（股票） | $C - P = S - \frac{X}{1+rt} - D$ | $S - Xe^{-rt} - D$ | $S - X + Xrt - D$ |
| 盒式 | $\frac{X_h - X_l}{1 + rt}$ | $(X_h - X_l)e^{-rt}$ | $(X_h - X_l)(1 - rt)$ |
| roll（股票） | $\frac{X}{1 + r_s t_s} - \frac{X}{1 + r_l t_l} - D$ | $Xe^{-r_s t_s} - Xe^{-r_l t_l} - D$ | $X r (t_l - t_s) - D$ |
| 時間盒式（股票） | $\frac{X_l}{1 + r_l t_l} + D - \frac{X_s}{1 + r_s t_s}$（買近月 $X_s$ 合成、賣遠月 $X_l$ 合成） | 對應連續版 | — |

組成：多頭盒式 = 多頭買權價差 + 空頭賣權價差；多頭 roll = 多頭買權日曆 + 空頭賣權日曆；時間盒式 = 兩個對角價差 = 盒式 ± roll。

## 交易員視角

- **Optibook 的雙掛牌（dual listing）與 ETF/期貨挑戰** 本質上就是本章的套利思維：同一經濟曝險在兩個市場有兩個價格。選擇權做市時，把每個履約價的買權、賣權、標的報價綁在平價上，你的報價就不會被對手用合成部位「套」。
- **先做哪一腿？** 執行風險在 Optibook 很真實：其他隊伍的 bot 速度很快。若你發現 combo 偏貴，先在流動性最差的那腿掛限價單，成交後立刻用 IOC 打流動性好的腿（通常是標的）。
- **部位上限 = 套利的天花板**：conversion/reversal 吃選擇權與標的兩邊的額度；盒式只吃選擇權額度。若標的已滿倉，可以考慮用盒式或三方組合。
- **「Positions never expire」**：Optibook 的部位不會自動平掉（與真實市場不同），但若有到期結構，pin risk 的教訓仍然適用——不要把大量價平空頭帶到到期。
- **delta 不是 0**：本章的結算風險說明，看似中性的套利部位可能帶有方向；大規模部位要用真實的 delta（例如 $100/(1+rt)$）避險。

## 常見誤區

1. **誤解**：「conversion、reversal、box 是無風險套利。」→ **正解**：有執行、pin、結算、利率、股利風險；盒式較低但仍有 pin 與（美式時的）提前履約風險。
2. **誤解**：「平價不成立就一定有套利。」→ **正解**：可能是你的利率或股利假設錯；先算隱含利率與隱含股利。
3. **誤解**：「價平選擇權到期一定不會被履約。」→ **正解**：履約常比在市場買賣標的便宜，很多價平選擇權會被履約，這正是 pin risk 的來源。
4. **誤解**：「股票型結算的期貨選擇權，合成期貨 delta 就是 100。」→ **正解**：是 $100/(1+rt)$；搭配真實期貨的 conversion 有淨 delta。
5. **誤解**：「盒式等於兩個日曆價差的差，roll 等於兩個垂直價差的和。」→ **正解**：剛好相反——盒式 = 垂直價差的和；roll = 日曆價差的差。
6. **誤解**：「有合成價格更好就是有套利。」→ **正解**：有買賣價差時，合成可以讓你更便宜地建立部位，但不代表可以無風險獲利（例題 15-12）。

## 重點摘要

| 項目 | 規則 |
|---|---|
| conversion | +標的 −C +P；combo 太貴時做 |
| reversal | −標的 +C −P；combo 太便宜時做 |
| 平價（一般式） | $C - P = (F - X)/(1+rt)$ |
| 股票遠期 | $F = S(1+rt) - D$ |
| 快速近似 | $C - P \approx S - X + Xrt - D$ |
| 隱含利率 | $r = \frac{(C - P - S + X + D)/X}{t}$ |
| 隱含股利 | $D = S - C + P - X + Xrt$ |
| 合成期貨 delta（股票型結算選擇權） | $100/(1+rt)$ |
| conversion（股票）| rho 負、股利正 |
| 盒式 | 價值 = 履約價差現值；= 借貸；= 買權價差 + 賣權價差 |
| roll（jelly roll） | $X/(1+r_st_s) - X/(1+r_lt_l) - D \approx Xr\Delta t - D$；= 買權日曆 − 賣權日曆 |
| 時間盒式 | = 盒式 ± roll；= 兩個對角價差 |
| pin risk | 實物交割、到期剛好在履約價；現金結算無 |

## 練習題

> **怎麼練**：先做 ⭐ 必做題（A1、B1、B3、C1）。卡住就先打開「提示」，還是不會再看解答。其他題目選做，想加深或準備面試時再回來。

### A. 概念題

**A1.** ⭐ combo（C − P）相對標的偏貴時，應做 conversion 還是 reversal？寫出三腿。

<details><summary>提示</summary>

combo 偏貴就要「賣 combo」。賣 combo = 賣買權 + 買賣權（合成空頭），那真的標的要買還是賣才能對沖？

</details>

<details><summary>解答</summary>

conversion：賣買權、買賣權（賣出偏貴的 combo，即合成賣出標的），同時買進真實標的。

</details>

**A2.** 為什麼現金結算的指數選擇權沒有 pin risk？

<details><summary>解答</summary>

到期時只以現金支付履約價與結算價的差額，不產生任何標的部位。pin risk 的本質是「不知道會不會被指派，因而不知道隔天會不會多出標的部位」，現金結算沒有這個不確定性。

</details>

**A3.** 一個 conversion 用的是股票型結算的期貨選擇權與（期貨型結算的）期貨。為什麼它偏多？

<details><summary>解答</summary>

期貨的損益每日以現金結算，選擇權的損益要到平倉或到期才實現。期貨上漲時，期貨部位立刻入帳、可以生息，而選擇權（合成空頭）的虧損只是帳面；下跌時則要為期貨的變動保證金融資，選擇權獲利卻未實現。所以上漲對部位較有利，淨 delta 為正，約 $100 - 100/(1+rt)$。

</details>

**A4.** 為什麼賣出盒式等於借錢？

<details><summary>解答</summary>

賣出盒式今天收到（約）履約價差的現值，到期時必須支付恰好等於履約價差的金額（歐式、現金結算時沒有其他不確定性）。今天收錢、未來付固定金額，就是借款；隱含利率由盒式成交價決定。

</details>

**A5.** 盒式可以拆成哪兩個價差？roll 呢？各是「和」還是「差」？

<details><summary>解答</summary>

多頭盒式 = 多頭買權垂直價差 + 空頭賣權垂直價差（價格相加）。多頭 roll = 多頭買權日曆價差 + 空頭賣權日曆價差，以價格而言等於「買權日曆價差 − 賣權日曆價差」（價格相減）。

</details>

**A6.** 什麼是三方組合（three-way）？它解決了什麼問題、又帶來什麼新問題？

<details><summary>解答</summary>

把 conversion/reversal 中的真實標的換成 delta 接近 100 的深價內選擇權（多頭時買深價內買權或賣深價內賣權）。它消除了持有真實標的的融資、股利與結算方式差異等風險。但若標的往那張深價內選擇權的履約價移動，它不再像標的，整個部位不再像純套利。

</details>

### B. 計算題

**B1.** ⭐ 期貨型結算的期貨選擇權：105C = 4.80、105P = 2.15、期貨 107.90。是否有套利？怎麼做、賺多少？

<details><summary>提示</summary>

期貨型結算用 C − P = F − X。先算「應該的」F − X 和實際的 C − P，比較哪一邊便宜，就買便宜那邊、賣貴那邊。

</details>

<details><summary>解答</summary>

平價：C − P 應 = F − X = 2.90。實際 C − P = 2.65 < 2.90，combo 便宜 → reversal：買 105C、賣 105P、賣期貨 107.90。利潤 = 2.90 − 2.65 = **0.25**。

</details>

**B2.** 股票型結算期貨選擇權：期貨 512、500C = 21.40、利率 5%、3 個月（單利）。500P 應為多少？

<details><summary>解答</summary>

C − P = (512 − 500)/(1 + 0.05 × 0.25) = 12/1.0125 = 11.852。P = 21.40 − 11.85 = **9.55**。

</details>

**B3.** ⭐ 股價 47.30、4 個月、利率 6%、股利 0.40、45P = 1.25。用精確平價（先算遠期）求 45C；再用快速近似求 45C。

<details><summary>提示</summary>

精確：先算遠期 F = S × (1 + rt) − 股利，再算 (F − X) ÷ (1 + rt)，最後 C = P + (C − P)。近似：直接用 S − X + X × r × t − 股利。

</details>

<details><summary>解答</summary>

精確：F = 47.30 × (1 + 0.06 × 4/12) − 0.40 = 47.30 × 1.02 − 0.40 = 47.846；C − P = (47.846 − 45)/1.02 = 2.790；C = 1.25 + 2.79 = **4.04**。
近似：C − P ≈ 47.30 − 45 + 45 × 0.02 − 0.40 = 2.80；C ≈ **4.05**。

</details>

**B4.** 80C = 4.60、80P = 2.95、3 個月，你假設 r = 4%、D = 0.50，股票實際 82.05。求隱含股利（假設利率正確）與隱含利率（假設股利正確）。

<details><summary>解答</summary>

隱含股利 D = S − C + P − X + Xrt = 82.05 − 4.60 + 2.95 − 80 + 80 × 0.04 × 0.25 = 82.05 − 1.65 − 80 + 0.80 = **1.20**。
隱含利率 r = (C − P − S + X + D)/X/t = (1.65 − 82.05 + 80 + 0.50)/80/0.25 = 0.10/20 = **0.5%**。
（兩種解讀：市場預期股利大增到 1.20，或資金成本只有 0.5%——前者通常比較可能，例如有特別股利傳聞。）

</details>

**B5.** 股票型結算期貨選擇權，利率 8%、9 個月。合成期貨部位的 delta 是多少？做 200 組 conversion，淨 delta 約多少？

<details><summary>解答</summary>

100/(1 + 0.08 × 0.75) = 100/1.06 = 94.34。conversion = +期貨 100 − 合成 94.34 = +5.66 每組；200 組約 **+1,132 delta**（約 11 口期貨）。

</details>

**B6.** 90/100 盒式，股票型結算、5 個月、利率 4.8%（單利）。理論價值？若有人以 9.70 賣出該盒式，隱含借款年利率？

<details><summary>解答</summary>

**B7.** 股票 roll：4 月（2 個月）/7 月（5 個月）50 roll，利率 6%，兩到期間股利 0.30。精確值與近似值各為多少？若 50 買權日曆價差 1.85，50 賣權日曆價差應為多少？

<details><summary>解答</summary>

</details>

### C. 交易情境題

**C1.** ⭐ 到期前一天，你持有 400 組 120 reversal（+120C、−120P、−股票），股票收在 120.05，波動不大。你會怎麼處理？

<details><summary>提示</summary>

這是 pin risk：股價就貼在履約價。想想你空的是哪一張選擇權？如果沒被指派、你也沒履約，會留下什麼部位？再想怎麼提前縮小規模。

</details>

<details><summary>解答</summary>

這是典型的 pin risk：你空 120P，若到期剛好在 120，不知道會不會被指派。若被指派（買進股票）而你沒履約買權，股票空頭被抵銷沒問題；若沒被指派而你也沒履約買權，就留下 400 口裸空股票。處理：(1) 今天就主動縮小規模，例如找持有 120 conversion 的交易員以平價交叉平倉；(2) 或在市場上分批平掉 reversal（接受買賣價差成本）；(3) 剩餘部位在到期後第一時間檢查指派，用股票立即修正。不要賭到期價格。

</details>

**C2.** 你在 Optibook 為某股票選擇權做市，股票 bid/ask 31.95/32.00，30C 你打算報 2.40/2.50。利率與股利可忽略、天期很短。30P 應該報多少附近？若有人在你的 30P 賣價上大量買進，你如何避險？

<details><summary>解答</summary>

利率、股利忽略時 C − P ≈ S − X。中心：S ≈ 31.975 → C − P ≈ 1.975；C 中心 2.45 → P 中心 ≈ 0.475，可報 0.43/0.53 左右（寬度與買權相近）。若有人在 0.53 買走大量 30P，你空 30P：最直接的避險是組成 reversal 的一部分——買 30C（在 2.50 或更好）並賣股票，或者至少先賣股票對沖 delta，再找機會買回 30C。重點是把空頭賣權的 gamma/vega 用買權抵銷，delta 用股票處理。

</details>

### D. 挑戰題

**D1.** 證明「時間盒式 = 買近月盒式 + 賣較高履約價 roll」，並說明在**期貨選擇權**市場這個等式為何可能不成立。

<details><summary>解答</summary>

記 $\text{Syn}(m, X) = C_{m,X} - P_{m,X}$。時間盒式 $= \text{Syn}(s, X_1) - \text{Syn}(l, X_2)$。
近月盒式 $= \text{Syn}(s, X_1) - \text{Syn}(s, X_2)$；$X_2$ 的多頭 roll $= \text{Syn}(l, X_2) - \text{Syn}(s, X_2)$。
近月盒式 − roll $= \text{Syn}(s, X_1) - \text{Syn}(s, X_2) - \text{Syn}(l, X_2) + \text{Syn}(s, X_2) = \text{Syn}(s, X_1) - \text{Syn}(l, X_2)$ ✔。
在期貨選擇權市場，近月與遠月選擇權的標的通常是**不同**的期貨合約。roll 中的近月合成多頭與遠月合成空頭到期時交割的是兩種不同的期貨，標的不會互相抵銷，所以「roll」不是純粹的利率/股利結構，而包含兩個期貨月份的價差風險；上述等式在代數上仍成立，但 roll 與時間盒式的價值不再只由利率與股利決定。

</details>
