# 第 17 章　用選擇權避險（Hedging with Options）

## ⚡ 懶人包（5 分鐘）

> 時間不多？讀完這一段 + 做下方 ⭐ 必做題就能往下一章走。後面的完整講義當「查字典」用，卡住再回來翻。

**一句話**：選擇權就是保險。買選擇權 = 付保費買保單（履約價離現價多遠就是自負額）；賣選擇權 = 收一點錢換有限的保護。每種避險都是「放棄一些好處，換掉一些風險」。

**你只需要先記住這 5 件事**

1. **保護一定有成本。** 現金保費、放棄的上檔，或某些情境下的額外風險，總要付一種。
2. **保護性選擇權：持股 + 買賣權 = 合成買權。** 最大損失 = (現價 − 履約價) + 保費。例：持股 120、買 110P 付 2.40 → 最多虧 12.40。
3. **掩護性賣出：持股 + 賣買權 = 合成賣出賣權。** 只保護到「股價 − 權利金」，再跌下去照樣虧；上檔被封頂。
4. **領口 = 持股 + 買賣權 + 賣買權 = 多頭垂直價差。** 上下都有限；兩張權利金相等就是零成本領口。
5. **隱含波動率高 → 買越少越好、賣越多越好；低 → 反過來。** 用 delta 決定保護比例：想保一半就湊 −50 delta。另外，波動小本身就有價值：長期複利 ≈ 算術平均 − 變異數 ÷ 2。

**必背卡**

| 要算什麼 | 怎麼算 |
|---|---|
| 保護性賣權最大損失 | (股價 − 履約價) + 保費 |
| 掩護性買權保護到 | 股價 − 權利金 |
| 掩護性買權最大獲利 | 履約價 − 股價 + 權利金 |
| 領口最大損失／獲利 | 股價 − 賣權履約價 ± 淨成本／買權履約價 − 股價 ± 淨成本 |
| 現金擔保賣權（歐式）存款 | 履約價 ÷ (1 + rt) |
| 投資組合保險持股 | 虛擬買權 delta × 原始持股 |

## 本章定位

期貨與選擇權最初都是保險契約：把持有標的的風險轉給別人。期貨幾乎把全部風險轉出，選擇權只轉出一部分，因此更像傳統保單。本章從避險者的角度出發：保護性選擇權、掩護性賣出、領口（collar）、結合波動率判斷的進階避險、降低報酬波動的價值，以及用動態避險「自製」選擇權的投資組合保險。前置：[ch08](ch08_dynamic_hedging.md)（動態避險）、[ch12](ch12_bull_bear_spreads.md)（垂直價差）、[ch14](ch14_synthetics.md)（合成部位）。

## 學習目標

1. 能分辨自然多頭與自然空頭，並說明任何避險都是「放棄某些情境的利益，換取另一些情境的保護」。
2. 能計算保護性買權/賣權的成本、最差結果，並指出它等價於哪個合成選擇權。
3. 能計算掩護性賣出（covered write、buy/write）的保護範圍、最大獲利，以及現金擔保賣權所需的存款。
4. 能建構領口並說明它等價於垂直價差、其 Greeks 由履約價位置決定，並找出零成本領口。
5. 能依隱含波動率高低選擇「買少賣多」或「買多賣少」的避險結構，並用 delta 決定避險比例。
6. 能用算術平均、幾何（複利）報酬、標準差與夏普比率說明降低波動的價值。
7. 能說明投資組合保險（選擇權複製）的做法與 1987 年失效的原因。

## 核心概念

### 17.1 避險者與避險成本

> 💡 **一句話**：先搞清楚自己是自然多頭還是空頭；每個避險都是放棄某些好處、換取某些保護。

**自然多頭與自然空頭**（natural long / natural short）：
- 商品生產者是自然多頭（價格漲，賣得多）；使用者是自然空頭（價格跌，買得便宜）。
- 利率方面：放款者是自然多頭（利率升有利），借款者是自然空頭。
- 也有人是自願建立部位後想暫時降低風險：投機者、或預期短期下跌但不想賣出持股的基金經理（避險可能比賣出再買回便宜）。

**避險有成本**，可能是明顯的現金支出，也可能是喪失的獲利機會或某些情境下的額外風險。**每一個避險決策都是取捨**：多頭避險者想保護下檔，幾乎一定要放棄部分上檔；空頭避險者想保護上檔，就要放棄部分下檔。

### 17.2 保護性買權與賣權（Protective Calls and Puts）

> 💡 **一句話**：買選擇權當保險：履約價距離是自負額、權利金是保費；持股 + 買賣權 = 合成買權。

最簡單的避險：多頭部位買賣權、空頭部位買買權。
- 履約價與現價的距離 ≈ 保單的**自負額**；
- 選擇權價格 ≈ **保費**。

**例題 17-1**（自創）台灣某公司 6 個月後要支付 US$2,000,000 貨款，等於持有美元的空頭部位（美元升值就要付更多台幣）。現在 USD/TWD = 31.50。

- 若美元 6 個月後仍 31.50：成本 NT$63,000,000；升到 32.80：NT$65,600,000。
- **避險**：買 6 個月、名目 US$2,000,000 的 32.00 美元買權，權利金 0.30 → 保費 NT$600,000。
  - 到期美元 > 32.00：履約，以 32.00 買美元；含保費最多每美元 32.30，總成本上限 **NT$64,600,000**。
  - 到期美元 < 32.00：放棄履約，在市場買。例如 30.80：付 61,600,000 + 600,000 = **NT$62,200,000**，仍保留美元貶值的好處。

不同履約價的取捨：

| 美元買權 | 權利金 | 保費（NT$） | 完全保護的起點 |
|---|---|---|---|
| 31.50 | 0.55 | 1,100,000 | 31.50 以上 |
| 32.00 | 0.30 | 600,000 | 32.00 以上 |
| 32.50 | 0.15 | 300,000 | 32.50 以上（之前自負） |

**利率版：上限（cap）與下限（floor）**
- 浮動利率借款者（利率空頭）買**利率買權 = cap**：利率再高，借款成本不超過履約利率。
- 浮動利率放款者（利率多頭）買**利率賣權 = floor**：利率再低，收益不低於履約利率。

**合成觀點**（第 14 章）：

$$\text{空頭標的} + \text{買買權} \approx \text{合成買賣權}$$
$$\text{多頭標的} + \text{買賣權} \approx \text{合成買買權}$$

例題 17-1 的公司（空美元 + 買 32.00 美元買權）等於持有一張 32.00 美元賣權：上檔風險有限、下檔獲利開放。

```
多頭標的 + 保護性賣權 = 合成買權
損益│            ／
    │          ／
  0 │--------／------  標的
    │_______／  ← 最大損失 = (現價 − 履約價) + 保費
           X
```

選哪個履約價取決於避險者能承受的風險，但有一點確定：**保護一定有成本**。

### 17.3 掩護性賣出（Covered Writes）

> 💡 **一句話**：賣選擇權收權利金，只保護到權利金那麼多、上檔被封頂；持股 + 賣買權 = 合成賣出賣權。

不想付保費的避險者，可以**賣出**選擇權對抗既有部位（covered write / overwrite）：立即收到權利金，提供**有限**保護，但不再有確定的最大損失。

**例題 17-2**（股價 80，3 個月，波動率 25%，利率 0）持股者擔心短期下跌：

| 賣出 | 收入 | 保護到（損益兩平） | 上檔 | 時間價值 |
|---|---|---|---|---|
| 75C（價內） | 6.87 | 73.13 | 被以 75 叫走；最多賺 1.87 | 1.87 |
| 85C（價外） | 2.08 | 77.92 | 漲到 85 前都參與；最多賺 7.08 | 2.08 |

- 價內：保護多、上檔少；價外：保護少、上檔多。
- 價平：時間價值最大，市場不動時增值最多，是最常見的選擇。

**合成觀點**：

$$\text{多頭標的} + \text{賣買權} \approx \text{合成賣賣權}$$
$$\text{空頭標的} + \text{賣賣權} \approx \text{合成賣買權}$$

持股 + 賣 85C ≡ 賣 85P。

**Buy/write**：同時買股票、賣買權，可以當成單一價格報價（股價 − 買權價）。股價 80、85C 2.08 → 85 buy/write = 77.92；做市者可能報 77.82–78.02（77.82 願意買股賣權；78.02 願意賣股買權）。交易所甚至編製追蹤此策略的指數（例如每月賣出略價外一個月指數買權的 buy/write 指數）。

**用賣出選擇權設定目標價**：
- 持股者願意在 85 賣出 → 賣 85C：漲到 85 就被叫走（本來就想賣），沒漲到則白賺權利金。
- 想在 70 買進的人 → 賣 70P：跌破 70 就被指派買進（本來就想買），沒跌則白賺權利金。公司買回庫藏股也常用這招。
- 差別在**擔保**：賣買權以持股擔保；賣賣權需要**現金擔保**（cash-secured put），存入履約價；若是歐式不會提前履約，只需存履約價的現值 $X/(1+rt)$。例：70P、6 個月、利率 4% → 70/1.02 = **68.63**。

**買保護還是賣掩護？** 理論上與交易員一樣：比較價格與價值。隱含波動率偏低 → 買保護性選擇權；偏高 → 賣掩護性選擇權。但實務常更重要：若某價位以外的行情會威脅公司生存，就該買那個履約價的保護，即使理論上偏貴。（選擇權看起來「貴得離譜」時通常有原因。）

許多避險者嫌保費「多半白付」——的確，大多數保護性選擇權到期都沒價值。但大多數人仍為房子、汽車買保險，而絕大多數保單也從未理賠；人們買保險是為了安心，不是為了賺錢。需要明確保護時，買選擇權可能就是最好的選擇。

### 17.4 領口（Collars）

> 💡 **一句話**：買保護、賣掩護，就是一個垂直價差：上下都有限，權利金互抵就是零成本領口。

**同時買保護性選擇權、賣掩護性選擇權**：以低成本取得明確保護，同時保留部分有利行情。又稱 fence、tunnel、cylinder、range forward、split-strike conversion。

- **多頭領口**（long collar）：多頭標的 + 買賣權 + 賣買權。
- **空頭領口**（short collar）：空頭標的 + 買買權 + 賣賣權。

**例題 17-3**　持股 80，買 75P（1.87）、賣 85C（2.08）：淨收 0.21。

| 到期股價 | 損益 |
|---|---|
| ≤ 75 | 75 − 80 + 0.21 = **−4.79**（下限） |
| 80 | +0.21 |
| ≥ 85 | 85 − 80 + 0.21 = **+5.21**（上限） |

**合成觀點**：多頭標的 + 買 75P = 合成 75C；再賣 85C → **75/85 多頭買權垂直價差**。空頭領口 = 空頭垂直價差。兩者都是有限風險、有限報酬。

既然是垂直價差，就有第 12 章的特性：
- 多頭領口 delta 恆正，空頭領口 delta 恆負。
- 標的較靠近**保護性**選擇權 → 通常正 gamma、負 theta、正 vega；較靠近**掩護性**選擇權 → 負 gamma、正 theta、負 vega。

| 股價 | delta | gamma | theta（每日） | vega |
|---|---|---|---|---|
| 76（靠近 75P） | +0.36 | +0.012 | −0.006 | +0.042 |
| 80（中間） | +0.38 | −0.003 | +0.002 | −0.011 |
| 84（靠近 85C） | +0.35 | −0.014 | +0.009 | −0.063 |

兩邊都不太遠時，Greeks 互相抵銷得很小；也可以刻意挑履約價讓領口接近 gamma、theta 或 vega 中性。

**零成本領口**：保護性選擇權價格 = 掩護性選擇權價格。本例要讓賣出買權也收 1.87，履約價約 **85.8**。保護性較貴時，損益中段落在標的損益線**之下**；較便宜時（本例淨收 0.21）落在**之上**。

**基本避險策略總表**：

| 部位 | 避險 | 優點 | 缺點 |
|---|---|---|---|
| 多頭標的 | 賣期貨/遠期 | 無下檔風險 | 無上檔獲利 |
| | 買保護性賣權 | 下檔有限、上檔無限 | 保費 |
| | 賣掩護性買權 | 部分下檔保護（= 權利金） | 下檔仍無限、上檔有限 |
| | 多頭領口 | 下檔有限 | 上檔有限 |
| 空頭標的 | 買期貨/遠期 | 無上檔風險 | 無下檔獲利 |
| | 買保護性買權 | 上檔有限、下檔獲利無限 | 保費 |
| | 賣掩護性賣權 | 部分上檔保護（= 權利金） | 上檔仍無限、下檔獲利有限 |
| | 空頭領口 | 上檔有限 | 下檔獲利有限 |

### 17.5 進階避險策略（Complex Hedging Strategies）

> 💡 **一句話**：隱含波動率高就少買多賣、低就多買少賣，用 delta 決定保護比例。

多數避險者不是專業選擇權交易員，最常用的是單一選擇權。若願意分析波動率與 delta，就能設計更多樣的避險。先問三件事：

1. 需要防範**最壞情境**（災難保險）嗎？
2. 要消除目前方向風險的**多少比例**？
3. 願意承擔哪些**額外風險**？

**需要災難保險** → 只能買選擇權，剩下的問題是買哪個履約價、買幾張。

**例題 17-4　隱含波動率偏高時**（期貨 100、3 個月；你認為合理波動率 24%，市場隱含 30%）。多頭避險者想保留一半多頭，即用總 delta −50 的賣權避險：

| 方案 | 總 delta | 理論上多付 |
|---|---|---|
| 買 1 張 100P（delta −47） | −47 | 1.19 |
| 買 2 張 92P（各 −26.4） | −52.8 | 2 × 0.94 = 1.89 |

買越多張高估的選擇權，多付越多。若完全不在乎上檔，而選擇權偏貴，乾脆用期貨/遠期避險；要保留上檔，就盡量買少：想消除 75% 風險，買 1 張 delta −75 的賣權，而不是 3 張 −25 的。

> **原則**：其他條件相同，**隱含波動率高 → 買越少越好、賣越多越好；隱含波動率低 → 買越多越好、賣越少越好。**

**比率賣出（ratio write）的代價**：隱含偏高時，若避險者願意承擔掩護性買權的下檔風險，理論上可以賣多張價外買權湊出 delta 50（而非 1 張價平）。但賣出的買權超過持股，上檔也變成無限風險——大漲時所有買權都會被指派。多數避險者只願意在「自然部位的方向」承擔無限風險；兩邊都無限風險就是在做波動率交易了。這沒有錯，但真正的避險者別忘了初衷：保護既有部位、壓低保護成本。

**用 1:1 波動率價差避險**：以 delta 選擇日曆價差或蝶式，提供某價格區間內的部分保護（整體仍保留無限的上檔風險與下檔獲利）。

- **隱含偏低**、標的 100、保護**空頭**部位：買 110 買權日曆價差（買遠月、賣近月），正 delta 且低隱含使多頭日曆價差便宜。若 delta +25，想保護 50% → 每單位空頭標的買 2 組。
- **隱含偏高**：改賣日曆價差，就要選**較低**履約價才有正 delta：賣 90 買權日曆價差（買近月、賣遠月）。delta +25、想保護 75% → 每單位賣 3 組。

**用垂直價差避險**：以價平選擇權為核心（第 12 章）。保護**多頭**部位要用空頭垂直價差（買高、賣低）：
- 隱含偏高：**賣出價平**、買較高履約價（例如賣 100、買 110）。
- 隱含偏低：**買進價平**、賣較低履約價（例如買 100、賣 90）。

兩者都有負 delta，且因價平選擇權對波動率最敏感，都帶正理論優勢。

選擇太多會讓避險者想放棄選擇權。較好的做法：挑 4–5 個合理策略，依自己的市場看法與願意承擔的風險比較風險報酬特性，再做決定。

### 17.6 以避險降低波動（Hedging to Reduce Volatility）

> 💡 **一句話**：波動越大，長期複利被拖得越多；平均報酬最高的人不一定最後賺最多。

避險除了防範不利行情，還能**降低部位的波動**——這本身就有價值。

**例題 17-5**（自創，五年年報酬）

| 經理人 | 第 1 年 | 第 2 年 | 第 3 年 | 第 4 年 | 第 5 年 | 算術平均 | 五年總報酬 | 標準差 | 夏普比率 |
|---|---|---|---|---|---|---|---|---|---|
| A | +16% | −10% | +24% | −6% | +18% | 8.40% | **+43.59%** | 15.32% | 0.548 |
| B | +30% | −24% | +36% | −20% | +28% | 10.00% | +37.59% | 29.39% | 0.340 |
| C | +45% | +10% | −38% | +70% | −30% | 11.40% | +17.68% | 46.69% | 0.244 |
| D | +7.8% | +7.8% | +7.8% | +7.8% | +7.8% | 7.80% | **+45.58%** | 0 | — |

（總報酬 = 各年 (1 + 報酬) 連乘 − 1；標準差為樣本標準差。）

- C 的算術平均最高，五年下來卻最差：A 的總報酬比 C 多約 26 個百分點。
- 無聊的 D 平均最低，總報酬卻最高。
- 原因：複利成長率約等於 **算術平均 − 變異數/2**。波動越大，這個「波動拖累」越大。例如 C：$0.114 - 0.4176^2/2 \approx 2.7\%$/年（實際幾何平均約 3.3%）。

高波動也不是不能接受——只要平均報酬夠高來補償。這種取捨常用**夏普比率**（Sharpe ratio）衡量：

$$\text{Sharpe} = \frac{\text{平均報酬}}{\text{報酬標準差}}$$

（實務上常用超額報酬，即扣除無風險利率後的報酬。）越大代表每單位風險換到越多報酬。

### 17.7 投資組合保險（Portfolio Insurance）

> 💡 **一句話**：沒有選擇權就用動態避險自製；但 1987 年證明它在最需要時最貴。

**情境**：持有股票，想買保護性賣權，但市場上沒有這檔股票的選擇權。

持股 + 賣權 ≡ 買權。所以你真正想要的是**一張同履約價、同到期的買權部位**——那就用動態避險**複製**它：

1. 自訂履約價與到期日（沒有掛牌限制）；股價、利率取自市場；波動率用歷史資料估計。
2. 用模型算出這張「虛擬買權」的 delta，把持股調整到 delta × 原始持股。
3. 定期重算 delta、調整持股；到期日買回到 100%。

**例題 17-6**　持有 2,000 股。
- 虛擬買權 delta 0.70 → 持股應為 1,400 股 → 賣出 600 股。
- 之後股價下跌，delta 降為 0.58 → 持股應為 1,160 股 → 再賣 240 股。
- 股價回升時 delta 上升 → 買回。持續到到期。

這就是第 8 章的動態避險，只是目的不同：第 8 章是捕捉市場價格與理論值的差；這裡沒有選擇權可以買賣，而是**複製選擇權的特性**，理論上達到與買保護性賣權相同的結果。

**基金規模的應用**：$2 億美元的投資組合，想保住 $1.8 億的下限 → 買「$1.8 億的賣權」，或複製「$1.8 億的買權」。1987 年以前很盛行，尤其是追蹤大盤的投資組合；為降低交易成本，多半用**指數期貨**來調整總曝險，而不是買賣成分股。有些公司收費代為決定波動率、模型並執行期貨調整。

**1987 年股災後的教訓**：
- 只有在輸入（尤其波動率）正確、模型假設符合現實時才有效。崩盤時波動率暴增，原先的波動率輸入嚴重錯誤；
- 價格跳空、流動性枯竭，連續調整的假設失效 → 複製成本遠高於預期；
- 有研究認為，保險機構在下跌中被迫賣出越來越多期貨，加劇了崩盤。

此後投資組合保險大多不再受青睞。教訓：**自製的選擇權，在你最需要它的時候，可能最貴**；掛牌選擇權的權利金至少是事先確定的。

## 交易員視角

- **你是避險者的對手方**：在 Optibook 做市時，大量買保護性賣權或賣掩護性買權的流量，會推高下檔賣權、壓低上檔買權的隱含波動率（波動率偏斜，第 24 章）。理解避險者的需求，能幫你預期哪一側的報價會被打。
- **用領口思維管理自己的部位**：若你的選擇權做市部位累積大量標的多頭 delta（例如從 ETF/期貨套利帶來），又碰到部位上限，買價外賣權、賣價外買權的「領口」能以近乎零成本限制尾端損失。
- **動態避險 = 自製選擇權**：你的 delta 避險迴圈本質上就是投資組合保險的引擎。Optibook 的價格跳動限制與流動性不足，正是 1987 年問題的縮影：急跌時你可能無法以理論價格調整，避險成本遠高於模型預期。
- **降低波動本身有價值**：比賽或真實交易都一樣，穩定的 PnL 曲線（高夏普）比偶爾大賺大賠更能長期存活；避險就是用一點期望值換取更窄的結果分布。

## 常見誤區

1. **誤解**：「保護性選擇權大多到期沒價值，所以買它是浪費。」→ **正解**：保險的價值在於限制災難；大多數保單也不會理賠。
2. **誤解**：「掩護性買權提供完整的下檔保護。」→ **正解**：只保護到權利金那麼多，之後下檔仍然無限。
3. **誤解**：「領口是一種全新的策略。」→ **正解**：多頭領口就是多頭垂直價差，風險特性完全依第 12 章分析。
4. **誤解**：「隱含波動率高時，應該多買幾張價外賣權來降低單價。」→ **正解**：高隱含時應買越少越好；多張高估的選擇權讓你多付更多。
5. **誤解**：「算術平均報酬最高的經理人，長期累積報酬也最高。」→ **正解**：複利報酬約為算術平均減去變異數的一半，高波動會侵蝕長期成果。
6. **誤解**：「投資組合保險的成本可以事先確定。」→ **正解**：複製成本取決於實現波動率與能否連續調整；波動暴增、跳空時成本遠超預期。

## 重點摘要

| 主題 | 公式 / 規則 |
|---|---|
| 保護性賣權 | 多頭標的 + 買 P ≈ 合成買 C；最大損失 = (S − X) + 保費 |
| 保護性買權 | 空頭標的 + 買 C ≈ 合成買 P；最大損失 = (X − S) + 保費 |
| 掩護性買權 | 多頭標的 + 賣 C ≈ 合成賣 P；保護到 S − 權利金 |
| 掩護性賣權 | 空頭標的 + 賣 P ≈ 合成賣 C |
| Buy/write 報價 | 股價 − 買權價 |
| 現金擔保賣權（歐式） | 存款 $X/(1+rt)$ |
| 多頭領口 | 多頭標的 + 買 P + 賣 C = 多頭垂直價差 |
| 零成本領口 | 保護性與掩護性權利金相等 |
| 避險數量原則 | 高隱含：少買多賣；低隱含：多買少賣 |
| 部分避險 | 用 delta 決定比例，例如 −50 delta 保護一半 |
| 複利 vs 算術平均 | 幾何 ≈ 算術 − σ²/2 |
| 夏普比率 | 平均報酬 / 標準差 |
| 投資組合保險 | 動態複製（持股 = delta × 原持股）；假設失效時代價高 |

### A. 概念題

**A1.** 航空公司對油價是自然多頭還是空頭？浮動利率放款的銀行呢？各適合買哪種保護性選擇權？

<details><summary>解答</summary>

航空公司要買油，油價上漲不利 → 自然空頭 → 買油價買權（cap 的概念）。浮動利率放款者利率上升有利 → 利率自然多頭 → 買利率賣權（floor）。

</details>

**A2.** ⭐ 為什麼「持股 + 買保護性賣權」等於持有買權？

<details><summary>提示</summary>

畫畫看：股價跌破履約價時，股票的虧損被什麼抵銷？漲上去時又怎樣？這條損益線像哪一種選擇權？

</details>

<details><summary>解答</summary>

合成關係：S + P = C（同履約價、同到期，忽略利息）。持股在履約價以下的虧損由賣權抵銷，以上則參與上漲——就是買權的形狀，保費即買權權利金的對應成本。

</details>

**A3.** 價平掩護性買權為什麼是最常見的選擇？

<details><summary>解答</summary>

價平選擇權時間價值最大；若市場維持在現價附近，以價平賣出的掩護部位增值最多。它在保護程度（介於價內與價外之間）與上檔參與之間取得折衷。

</details>

**A4.** 為什麼賣出多張價外買權來避險持股（ratio write）通常不符合避險者的目標？

<details><summary>解答</summary>

賣出的買權多於持股，上檔變成無限風險；加上掩護性部位原本的下檔無限風險，兩邊都暴露。這已是波動率交易，而避險者通常只願意在自然部位的方向承擔無限風險。

</details>

**A5.** 為什麼投資組合保險在 1987 年失效？

<details><summary>解答</summary>

複製成本取決於實現波動率與能否連續調整。崩盤時波動率暴增（輸入錯誤），價格跳空、流動性不足（連續調整假設失效），使複製成本遠高於預期；同時大量保險機構同步賣期貨，可能加劇下跌。

</details>

### B. 計算題

**B1.** 持股 120，買 110P 付 2.40。到期最大損失？損益兩平點？

<details><summary>解答</summary>

最大損失 = (120 − 110) + 2.40 = **12.40**（股價 ≤ 110）。損益兩平 = 120 + 2.40 = **122.40**。

</details>

**B2.** ⭐ 持股 80，賣 85C 收 2.08。下檔保護到哪裡？最大獲利？若股價到期 70，損益？

<details><summary>提示</summary>

保護點 = 股價 − 收到的權利金。最大獲利發生在股價漲到 85 被叫走時：(85 − 80) + 權利金。股價 70 時，股票損益加上權利金（85C 到期沒價值）。

</details>

<details><summary>解答</summary>

保護到 80 − 2.08 = **77.92**；最大獲利 = 85 − 80 + 2.08 = **7.08**；股價 70 時 = 70 − 80 + 2.08 = **−7.92**。

</details>

**B3.** 歐式現金擔保賣權：賣 70P、6 個月、利率 4%（單利）。至少要存多少現金？

<details><summary>解答</summary>

70/(1 + 0.04 × 0.5) = 70/1.02 = **68.63**。

</details>

**B4.** ⭐ 持股 50，買 46P 付 0.95、賣 55C 收 0.70。淨成本？到期最大損失與最大獲利？

<details><summary>提示</summary>

先算淨成本 = 付的賣權費 − 收的買權費。跌到 46 以下時賣權接手，損失 = (50 − 46) + 淨成本；漲到 55 以上被叫走，獲利 = (55 − 50) − 淨成本。

</details>

<details><summary>解答</summary>

淨付 0.25。最大損失 = 50 − 46 + 0.25 = **4.25**；最大獲利 = 55 − 50 − 0.25 = **4.75**。（等價於 46/55 多頭買權價差，以 4.25 的淨成本計：最大獲利 9 − 4.25 = 4.75。）

</details>

**B5.** 某經理人五年報酬為 +20%、−15%、+25%、−10%、+15%。算術平均、五年總報酬、樣本標準差、夏普比率（平均/標準差）各為多少？

<details><summary>解答</summary>

算術平均 = 35/5 = **7.0%**。總報酬 = 1.20 × 0.85 × 1.25 × 0.90 × 1.15 − 1 = 1.31963 − 1 = **+31.96%**。樣本標準差 ≈ **18.23%**。夏普 ≈ 0.07/0.1823 = **0.384**。

</details>

**B6.** 持有 5,000 股，複製一張保護性賣權。模型給虛擬買權 delta 0.64，之後變成 0.71。各時點應持股多少？第二次要買或賣多少股？

<details><summary>解答</summary>

第一次：5,000 × 0.64 = **3,200 股**（賣出 1,800）。第二次：5,000 × 0.71 = **3,550 股** → 買回 **350 股**。

</details>

### C. 交易情境題

**C1.** ⭐ 一家出口商 3 個月後會收到 US$5,000,000（美元多頭）。USD/TWD 31.80，3 個月 31.00 美元賣權 0.20、32.80 美元買權 0.20。公司董事會要求「最差匯率不得低於 31.00」且不想付保費。你建議什麼？有什麼代價？

<details><summary>提示</summary>

董事會要「最差不低於 31.00」→ 要買哪一種選擇權？不想付保費 → 再賣一張權利金一樣的選擇權來抵。想想這樣放棄了什麼。

</details>

<details><summary>解答</summary>

零成本多頭領口：買 31.00 美元賣權、賣 32.80 美元買權，權利金互抵。最差換匯 31.00（符合要求），代價是美元若升破 32.80，超過部分的利益放棄（最多換到 32.80）。等價於 31.00/32.80 多頭垂直價差。若董事會願意付保費，也可以只買賣權保留全部上檔。

</details>

**C2.** 你在 Optibook 累積了大量股票多頭（部位接近上限），隱含波動率明顯偏高。你想保護一半的部位約一週。比較：(a) 買 1 張接近 −50 delta 的價平賣權、(b) 買 2 張 −25 delta 的價外賣權、(c) 賣掉一半股票、(d) 賣價平買權。

<details><summary>解答</summary>

隱含偏高 → 買越少越好、賣越多越好。(b) 最差（買兩張高估選擇權）；(a) 比 (b) 好但仍付高估保費。(d) 收取高估權利金、正理論優勢，提供部分保護，但下檔仍無限。(c) 沒有波動率成本，若主要目標是降風險且市場可承受，最乾淨。若需要「最壞情況有底」，選 (a)；若只是想降低 delta 又看好波動率回落，選 (d) 或 (c)。

</details>

### D. 挑戰題

**D1.** (a) 證明對報酬 $r_i$ 的小幅波動，$\ln(1+r) \approx r - r^2/2$，由此推得「幾何平均報酬 ≈ 算術平均 − 變異數/2」。(b) 用例題 17-5 的經理人 A 驗證這個近似（母體變異數）。

<details><summary>解答</summary>

(a) 泰勒展開 $\ln(1+r) = r - r^2/2 + r^3/3 - \dots$。五年平均 $\frac1n\sum\ln(1+r_i) \approx \bar r - \frac{1}{2n}\sum r_i^2 = \bar r - \frac12(\sigma^2_{\text{母體}} + \bar r^2)$。幾何平均 $g$ 滿足 $\ln(1+g) \approx g - g^2/2$，兩邊的 $\bar r^2/2$ 與 $g^2/2$ 近似抵銷，得 $g \approx \bar r - \sigma^2/2$。
(b) A：$\bar r = 8.4\%$，母體標準差 13.71% → 變異數 0.01880 → $8.4\% - 0.94\% = 7.46\%$；實際幾何平均 $(1.4359)^{1/5} - 1 = 7.50\%$，相當接近。

</details>
